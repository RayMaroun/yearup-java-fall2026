A Fixed List of Choices (enum)

Optional: a capstone that keeps its choices as plain text is just as good. See what an enum adds, then decide.

The one idea

An enum is a type with a fixed list of values, and it is optional in your capstone: plain text works just as well. It helps for a short list that never changes while the program runs, like sizes: a typo becomes a compile error, each value can carry facts such as a price, and values() lines them up for a menu. It does not help for what the user types freely, like a name, or for a list that changes while the program runs.
