Class Diagram Notation

How to read and draw a class box. The box shows the name, the attributes and the methods; the arrow shows who extends whom. Type in the box to filter every row on the page, for example arrow, italic or protected.

Anatomy of one class box 5a · 1-1

the box
1 nameThe top band holds the class name, centered and bold.
2 attributesThe middle band lists the fields, one per line, written sign name: Type.
3 methodsThe bottom band lists the methods, one per line, written sign name(parameters): ReturnType.
empty bandA class with no fields or no methods keeps the band, just empty, so every box has three bands.

+ bark(): voidpublic void bark() { ... }
+ Dog(name: String, breed: String)public Dog(String name, String breed) { ... }
orderThe name comes first and the type after the colon, the opposite of Java. A constructor has no return type, so no colon at the end.

The inheritance arrow 5a · 1-1

two boxes
directionDraw the arrow from the child to the parent. The hollow triangle touches the parent.
read itSay it as a sentence: Dog is an Animal. If the sentence is false, there is no arrow.
only the newA child box lists only its own attributes and methods. What it inherits is not repeated.
many childrenEach child gets its own arrow to the same parent box.

Abstract in italics 5a · 2-2

two boxes
abstract classWrite the class name in italics.
abstract methodWrite the method line in italics. The concrete method printMessage() stays upright.
the childThe child writes the method again, upright, because now it has a body.
on paperSlant the letters of the name by hand so it reads as italic.

Drawing it in diagrams.net 5a · 1-1

1 · openGo to app.diagrams.net and choose where to save the file. Pick Create New Diagram, then Blank Diagram.
2 · a class boxIn the shapes panel on the left, type class in the search box. Drag the Class shape onto the page; it comes with three bands.
3 · the nameDouble-click the top band and type the class name.
4 · attributesDouble-click the middle band and type one attribute per line, such as - name: String.
5 · methodsDouble-click the bottom band and type one method per line, such as + getName(): String.
6 · a second boxDrag in a second Class shape and fill it in the same way, for the child, placed below the parent.
7 · the arrowHover over the child box and drag one of its blue arrows to the parent box. Click the line, and in the Format panel on the right, on the Style tab, change the line end at the parent to the hollow triangle (the block arrow that is not filled).
8 · italicsFor an abstract class or method, select the text and press Cmd+I (Mac) or Ctrl+I (Windows), or use the I button on the Text tab.
9 · saveChoose File, then Save, or File, Export as, PNG to share a picture.

What goes in a class diagram 5a · 1-1

PartShow it?
AttributesAlways, with the sign and the type.
Methods that do somethingAlways. They are what the class can do.
ConstructorsYes, when the class has one that takes values. It tells the reader what is needed to build the object.
Plain getters and settersNo. The attributes already imply them, and they bury the methods that matter.
A getter that calculatesYes. It is behavior, and there is no attribute behind it.

Common slips 5a · 1-1

SlipFix
The arrow points at the childTurn it around: the triangle belongs on the parent.
A filled or open arrowheadUse the hollow triangle for inheritance.
The parent's attributes repeated in the childDelete them. The arrow already says the child has them.
name String instead of name: StringName first, a colon, then the type.
No sign in front of a lineEvery attribute and method gets + - or #.
An abstract class in plain lettersItalicize the class name and the abstract method line.
