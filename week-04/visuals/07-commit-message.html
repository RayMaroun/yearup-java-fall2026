The Commit Message

One line that says what changed. Verb first, then the thing, then why if it helps.

The shape of the line

Verb

What the code does now, as an order: Add, Fix, Show, Remove, Rename. Not "added", not "fixing", not "update".

What changed

The method, the class, the screen or the file. Name it. "stuff", "code", "bug" and "changes" name nothing.

Why, if it helps

Optional. Adds the reason or the place: so the ledger loads, for the demo. Skip it when the first two parts say it all.

The one idea

A commit message is one line a stranger reads in the history and knows what changed. Verb first, the thing second, under 50 characters: Add loadTransactions to read the csv, Fix payment stored as a positive amount, Show ledger newest first. "update", "final" and "asdf" are the lines Raymond will ask about.
