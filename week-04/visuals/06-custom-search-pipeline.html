Two gates are filled, three are blank. Press Search to send the 8 rows through all five.

The one idea

One loop over the list, and for each of the five values the same two-part test: if the user typed something and the row does not match, skip it. A blank value skips the test, not the row. Five tests that all have to say yes is an AND, so the order of the gates never changes what comes out.
