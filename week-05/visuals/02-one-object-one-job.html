Six responsibilities, three objects. Each one is something an object knows or something it does.

The one idea

Each object owns its own responsibilities. A responsibility is something the object knows (data) or does (an action), and it lives with the specialist it belongs to, so there is one place to look for it. The Register asks the Bike for its price; it does not keep its own copy.
