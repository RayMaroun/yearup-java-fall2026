The one idea

A BigDecimal never changes: add, subtract, multiply and setScale each return a new one, so write cartTotal = cartTotal.add(price); Multiply grows the scale, setScale(2, RoundingMode.HALF_UP) brings it back to cents. Compare with compareTo, never == or equals, and give divide a scale and a rounding mode too.
