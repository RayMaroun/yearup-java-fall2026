p1 is a Person. Its three fields are private: main stands outside the box and can only use the door.

The one idea

Private fields, public door. Mark the fields private so no code outside the class can touch them, then give the class public getters to read them and setters to change them. The compiler holds the lock: p1.firstName in main does not compile, p1.getFirstName() does.
