Setup checklist 4a · 3-2

1 · dependency<!-- pom.xml, inside <project> --> <dependencies> <dependency> <groupId>org.junit.jupiter</groupId> <artifactId>junit-jupiter</artifactId> <version>5.10.2</version> <scope>test</scope> </dependency> </dependencies>
2 · reload Maven// click the small Maven icon that appears over pom.xml, or // Maven tool window, Reload All Maven Projects. Until then, @Test stays red.
3 · test foldersrc/test/java/com/pluralsight // same package as src/main/java/com/pluralsight
4 · test class// open Car.java, right-click, Generate..., Test..., JUnit5, OK // "JUnit5 library not found"? click Fix: it adds the dependency for you src/test/java/com/pluralsight/CarTest.java // one test class per class
5 · green arrow// click the green arrow in the gutter next to the class or one @Test // green check = passed, red mark = failed, with expected and actual

Assertions 4a · 3-2

AssertionExamplePasses when
assertEquals(expected, actual)assertEquals(15, car.getSpeed());the two values are equal; expected goes first, or the failure message reads backwards
assertNotEquals(unexpected, actual)assertNotEquals(0, car.getSpeed());the two values are different; equal fails
assertTrue(condition)assertTrue(car.getSpeed() > 0);the boolean is true
assertFalse(condition)assertFalse(car.getSpeed() > 100);the boolean is false
assertNull(value)assertNull(new Car().getMake());the value is null; the empty constructor never set make
assertNotNull(value)assertNotNull(car.getModel());the value is anything but null
