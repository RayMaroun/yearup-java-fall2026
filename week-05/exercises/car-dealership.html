Workshop 4w · Car Dealership

Car Dealership

A sales manager's desk app: search the lot, add a car, sell one, and the file keeps up.

What you are building

Your own project in your own repository. The program reads inventory.csv into a Dealership that holds a list of Vehicle objects. A menu lets the manager find vehicles by price, make and model, year, color, mileage or type, list them all, add one and remove one. Five classes, each with one job.

No sales, no customers, one dealership only. Every add or remove rewrites inventory.csv, so the next run starts where this one ended.

Where people get stuck

  • The dealership became a vehicle. The first line has three parts, not eight. Read it once before the loop and build the Dealership from it.
  • FileNotFoundException: inventory.csv. The file sits at the project root, next to pom.xml, not inside src.
  • NullPointerException on a search. That search still returns null from Phase 1. Make it return a list, even an empty one.
  • The file lost its first line after a save. saveDealership writes the dealership line first, then every vehicle.

The one idea

Each class has one job. Vehicle knows a car, Dealership keeps the list and searches it, DealershipFileManager talks to the file, UserInterface talks to the manager, Program only starts it all.
