Responsibilities at a Hotel

On paper, with your group: give every hotel object the things it knows and the things it does.

What you are building

A table that starts from your Objects at a Hotel list. Next to each object you write what it needs to KNOW and what it needs to DO, so the seven workbook scenarios can run.

No project, no code. Each responsibility belongs to one object only. Adding or dropping objects is allowed.

Do these in order

0 of 6 done

What a finished answer looks like

example: a gym, not a hotel
Member KNOW name, membership type DO book a class FrontDesk KNOW who is inside today DO scan a member card Trainer KNOW the classes they teach DO run a class ...one row per object

A different place on purpose. Yours is a hotel with more objects, and it will differ from other groups.

Where people get stuck

  • Two owners. A responsibility on two objects means none owns it. Pick one; the other asks it.
  • Only KNOW. Every scenario has a verb. Someone has to DO it.
  • One object does everything. Spread the work. A specialist does one job well.
  • Empty objects. An object with nothing to know or do can go.
