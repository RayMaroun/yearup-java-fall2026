Java matches the argument types in order · an exact match wins · an int can widen to a double, a double never becomes an int · a String never converts · two equal fits = ambiguous

The one idea

Java picks an overload by the types of the arguments, in order, before the program runs. An exact match wins; an int may widen to a double when nothing matches exactly; a String never turns into a number. No fit, or two equally good fits, and the call does not compile.
