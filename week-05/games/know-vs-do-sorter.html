KNOW = a piece of data the object stores, the brains · DO = an action the object performs, the muscle · most objects do both

The one idea

Something an object knows becomes a field; something it does becomes a method. Ask "is this a value I remember, or a job I carry out?" and the class almost writes itself: the nouns and numbers go at the top, the verbs go below them.
