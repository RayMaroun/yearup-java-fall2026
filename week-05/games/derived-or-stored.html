stored = there is a field with that name, the getter returns it · derived = no such field, the value is calculated from other fields

The one idea

A getter does not need a field of its own. If a value can be worked out from fields the object already has, like a full name from a first and last name, compute it in the getter instead of storing it twice. The caller cannot tell the difference.
