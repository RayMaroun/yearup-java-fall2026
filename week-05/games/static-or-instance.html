Static or Instance?

Each round is a member described in one line, or a one-line call. Press S if it belongs to the class (no object needed), I if it belongs to one object (you need an object to reach it).

Press Start. Keys S and I answer.

STATIC = one copy for the whole class, called on the class name · INSTANCE = one copy per object, called on a variable · ask: does it need one object's data?

The one idea

Ask whether the member needs one particular object's data. If it does (this learner's name, this account's balance), it is an instance member and you reach it through an object: alice.printDetails(). If it does not (a value everyone shares, a calculation that only needs its inputs), it is static and you reach it through the class: Learner.changeSchool("Lakeside Academy"), Math.sqrt(25).
