Errors and exceptions

Compile time error

A mistake in syntax or types that the compiler points out before the program can run at all.

System.out.printLn("Hello Raymond"); // printLn does not existSee it: Three Kinds of Errors

Logic error

The program runs and finishes but gives the wrong answer, because it does exactly what you wrote, not what you meant.

double finalPrice = price * discount; // 20.0, not 80.0See it: Three Kinds of Errors

Runtime error

The program compiles and starts, then stops in the middle because of bad input, a bad index, a missing file or something else unexpected.

listOfNames[3] // only indexes 0 to 2 existSee it: Three Kinds of Errors

Exception

The object Java creates to describe a runtime error; its type names what went wrong, and Exception is the parent of all of them.

catch (Exception ex) // catches any exceptionSee it: try and catch

Throw

What happens when a line fails: the line stops and the exception jumps to the nearest catch, or ends the program if there is none.

int result = firstNumber / secondNumber; // 0 here throwsSee it: try and catch

try block

The code you want to run that might throw; when a line inside it throws, the rest of the block is skipped.

try { ... }See it: try and catch

catch block

The code that runs only when the try block throws; the type in the parentheses says which exceptions it accepts.

catch (Exception ex) { ... }See it: try and catch

Handle

To catch an exception and do something sensible with it, like print a message, so the program keeps running instead of crashing.

See it: try and catch

Stack trace

The report Java prints for an exception: its type, its message, and the chain of method calls with line numbers that led to it.

e.printStackTrace();See it: try and catch

getMessage()

Returns the short text an exception carries, without the stack trace.

ex.getMessage() // "/ by zero"See it: try and catch

ArithmeticException

Thrown when a whole number is divided by zero.

10 / 0 // / by zeroSee it: try and catch

InputMismatchException

Thrown by scanner.nextInt() when the user types something that is not a whole number, like a letter.

int firstNumber = scanner.nextInt(); // user types abcSee it: try and catch

ArrayIndexOutOfBoundsException

Thrown when an array index is below 0 or at or past the array's length.

Index 6 out of bounds for length 6See it: Three Kinds of Errors

IndexOutOfBoundsException

The list version: get, set or remove with an index the ArrayList does not have.

kids.get(3) // size is 3, last index is 2See it: ArrayList Operations

IOException

The family of input and output errors when reading or writing a file; Java makes you catch it around file code.

catch (IOException e)See it: Reading a File Line by Line

FileNotFoundException

A kind of IOException, thrown by new FileReader when the file is not where Java looks for it.

new FileReader("missing.txt")See it: Reading a File Line by Line

Files

File

Characters saved on disk under a name with an extension, like poem.txt; it is still there after the program ends.

See it: Reading a File Line by Line

Path

Where a file is: a bare name like poem.txt is a relative path, read from the working directory; a full path starts at the top of the drive.

"poem.txt" // relative

Working directory

The folder a running program treats as here; in IntelliJ it is the project root, so poem.txt sits next to pom.xml, not inside src.

See it: Reading a File Line by Line

FileReader

Opens a file for reading, one character at a time; on its own it has no readLine().

FileReader fileReader = new FileReader("poem.txt");See it: Reading a File Line by Line

BufferedReader

Wraps a FileReader, reads big blocks into a buffer, and hands you the text a whole line at a time.

BufferedReader bufferedReader = new BufferedReader(fileReader);See it: Reading a File Line by Line

Buffer

A block of memory that holds characters between the program and the file, so the disk is touched in big chunks instead of once per character.

See it: Reading a File Line by Line

readLine()

Returns the next line of the file as a String, without its line break.

String line = bufferedReader.readLine();See it: Reading a File Line by Line

null at end of file

readLine() returns null when there are no more lines, which is how the while loop knows to stop.

while ((line = bufferedReader.readLine()) != null)See it: Reading a File Line by Line

close()

Releases the file when you are done; on a writer it also pushes the last buffered text to disk, so a forgotten close can leave the file empty.

bufferedWriter.close();See it: Writing to a File

FileWriter

Opens a file for writing: creates it, or wipes and overwrites it if it already exists; write() adds no line break, so you add \n yourself.

fileWriter.write("Hello Everyone\n");See it: Writing to a File

BufferedWriter

Wraps a FileWriter and collects text in an 8K buffer, writing to the file only when the buffer fills or when you close it.

BufferedWriter bufferedWriter = new BufferedWriter(fileWriter);See it: Writing to a File

Append

Adding to the end of a file instead of overwriting it; pass true as FileWriter's second argument.

new FileWriter("tomato.txt", true)See it: Writing to a File

flush()

Pushes whatever is waiting in the buffer to the file now, without closing it; close() flushes for you.

bufferedWriter.flush();See it: Writing to a File

CSV

A plain text file with one record per line and the fields separated by a delimiter; the name means comma-separated values, but a pipe works too.

SUV|2026|Black

Delimiter

The character that sits between the fields of a line, like a comma or a pipe.

Pipe

The | character, a common delimiter because it rarely shows up in the data; split() needs it escaped.

line.split("\\|")See it: From One Line to One Object

split()

Cuts a line at every delimiter and returns the pieces as a String array.

String[] tokens = line.split(Pattern.quote("|"));See it: From One Line to One Object

Token

One piece of a split line; tokens[0] is the first field, and every token is a String until you parse it.

int year = Integer.parseInt(tokens[1]);See it: From One Line to One Object

Dates

java.time

The package of date and time classes that came with Java 8.

import java.time.LocalDate;See it: LocalDate, LocalTime, LocalDateTime

LocalDate

A date with no time, like a birthday; it prints as year-month-day.

LocalDate today = LocalDate.now(); // 2026-04-22See it: LocalDate, LocalTime, LocalDateTime

LocalTime

A time with no date, like a store's closing time; it prints hours, minutes, seconds and a fraction.

LocalTime.now() // 02:17:11.770918See it: LocalDate, LocalTime, LocalDateTime

LocalDateTime

A date and a time together, like a timestamp; it prints with a T between the two.

LocalDateTime.now() // 2026-04-22T02:17:11.771319See it: LocalDate, LocalTime, LocalDateTime

now()

The static method on each date and time class that returns the current value from the computer's clock.

LocalTime currentTime = LocalTime.now();See it: LocalDate, LocalTime, LocalDateTime

ISO 8601

The international layout year-month-day; the date classes print in it, and parse() reads it without a formatter.

2026-10-17See it: Date Patterns

DateTimeFormatter

Describes a layout with pattern letters, to read text in that layout or to print a date in it.

DateTimeFormatter.ofPattern("MM/dd/yyyy")See it: Date Patterns

Pattern

The letters given to ofPattern(): MM month, dd day, yyyy year, HH hour, mm minutes, E day name, MMM month name; case matters.

"E, MMM dd, yyyy HH:mm:ss"See it: Date Patterns

format()

Turns a date or time into a String in the formatter's layout; the date itself does not change.

String formattedDate = currentDate.format(formatter);See it: Date Patterns

parse()

Turns text into a date; the text must match the formatter's pattern exactly, or ISO when there is none, otherwise it throws DateTimeParseException.

LocalDate.parse("10/17/2026", dateTimeFormatter)See it: Date Patterns

Time zone

A region's offset from GMT; LocalDate, LocalTime and LocalDateTime have no time zone, they use the computer's local date and time.

See it: LocalDate, LocalTime, LocalDateTime

GMT

Greenwich Mean Time, the reference clock other time zones are counted from; New York is GMT-5 in winter and GMT-4 in summer.

Collections

Collection

An object that holds a group of other objects; informally, an array is one too.

See it: Array vs ArrayList

Collections Framework

The ready-made, tested collection classes that come with Java, so you never have to build and test your own.

See it: Array vs ArrayList

java.util

The package where ArrayList, List, HashMap and Collections live.

import java.util.ArrayList;

Generic type

The type in angle brackets that says what a collection holds; it must be a class, so a list of numbers uses Integer, not int.

List<Integer> numbers = new ArrayList<>();See it: Array vs ArrayList

ArrayList

A resizable array: it keeps the order you add in, grows as you add, shrinks as you remove, and prints in square brackets.

[Natalie, Brittany, Zachary]See it: Array vs ArrayList

List

The interface ArrayList belongs to; declaring the variable as List is the common style.

List<String> names = new ArrayList<>();See it: Array vs ArrayList

add()

Puts an element at the end; add(index, element) inserts it at that index and moves each later element up one index.

kids.add(0, "Natalie");See it: ArrayList Operations

get()

Returns the element at an index without removing it.

kids.get(0) // NatalieSee it: ArrayList Operations

set()

Replaces the element at an index; the size stays the same.

kids.set(2, "Zach");See it: ArrayList Operations

remove()

Takes out the element at an index, and each later element moves down one index to close the gap.

kids.remove(0);See it: ArrayList Operations

size()

The number of elements in the list right now; a list has size(), an array has length.

for (int i = 0; i < kids.size(); i++)See it: ArrayList Operations

Index (in a list)

A position counted from 0, as in an array, so the last element is at size() - 1.

See it: ArrayList Operations

for-each loop

Visits every element of a collection in order, with no index to manage.

for (String kid : kids)See it: ArrayList Operations

Collections.sort()

Sorts a list in place, A to Z for Strings; add Collections.reverseOrder() for Z to A.

Collections.sort(kids);See it: ArrayList Operations

HashMap

A collection of key/value pairs where you find a value by its key, not by its position.

HashMap<String, String> statesAndCapitals = new HashMap<>();See it: HashMap Lookup

Key

What you look a value up by; it does the job an index does in a list, but it can be any type you choose.

"TX"See it: HashMap Lookup

Value

What a key leads to; two keys can share the same value.

"Austin"See it: HashMap Lookup

Key/value pair

One entry in a map, a key and the value stored under it; a printed map shows each one as key=value.

{CT=Hartford, TX=Austin}See it: HashMap Lookup

put()

Stores a value under a key; if the key is already there, the new value replaces the old one.

statesAndCapitals.put("TX", "Austin");See it: HashMap Operations

Lookup

Finding a value by its key with get(); a key that is not in the map gives null, not an exception.

statesAndCapitals.get("OK") // nullSee it: HashMap Lookup

Unique key

Each key appears at most once in a map; putting the same key again overwrites its value instead of adding a second entry.

See it: HashMap Operations

values()

Returns every value in the map, ready for a for-each loop.

for (String value : statesAndCapitals.values())See it: HashMap Operations

keySet()

Returns every key in the map, often looped over to get each value.

for (String key : statesAndCapitals.keySet())See it: HashMap Operations

Hash function

Turns a key into a position in the map's storage; that makes lookup fast and decides the order a map prints in.

See it: HashMap Lookup

Insertion order

The order elements were added in; an ArrayList keeps it, a HashMap does not.

See it: HashMap Lookup

Agile

Agile

A way to manage a project in short repeated cycles that stays open to change and responds to it without going off the rails.

See it: Waterfall vs Agile

Waterfall

The opposite of Agile: plan everything up front, build every feature, test at the end, then ship, so nobody sees working software for a long time.

See it: Waterfall vs Agile

Agile Manifesto

The short document of the four values behind Agile, people, working software, customer collaboration and responding to change, backed by twelve principles.

See it: Waterfall vs Agile

Scrum

A popular Agile framework in which a self-organizing team works in sprints and reflects to keep improving.

See it: The Scrum Cycle

Sprint

A short, fixed period, often 2 to 3 weeks, in which the team completes a chosen amount of work.

See it: The Scrum Cycle

Product owner

The Scrum role that speaks for the customer and decides what the team works on first.

See it: The Scrum Cycle

Scrum master

The Scrum role that keeps the process running, clears obstacles, and usually facilitates the daily standup.

See it: The Scrum Cycle

Development team

The Scrum role that builds the product and is responsible for running its own standup.

See it: The Scrum Cycle

Daily standup

A short daily meeting: what did you do yesterday, what will you do today, where are you blocked.

See it: The Scrum Cycle

Blocker

Anything stopping you from moving forward; you raise it at standup so someone can help.

See it: The Scrum Cycle

Retrospective

A meeting at the end of a sprint to look back, hear from everyone, and agree on action items for the next one.

See it: The Scrum Cycle

User story

One feature written from the user's side: As a (role) I want (something) so that (benefit).

As a web site user I want a navigation bar so that I can switch between pagesSee it: A User Story

Requirement

Something the application must do; each one becomes one or more user stories.

See it: A User Story

Acceptance criteria

The checklist on a story that says exactly what must be true for it to count as done.

- [ ] Create the root directorySee it: A User Story

MVP

Minimum viable product: the first version with just enough features for early users to use it and give feedback.

See it: A User Story

Backlog

Every story not started yet, in priority order; on the board it is the Todo column.

See it: The Project Board

Kanban board

A board of columns, one per state of work, with a card per task that moves left to right.

See it: The Project Board

GitHub Projects

GitHub's project boards, the kanban tool used in this class; Trello and Asana do the same job.

See it: The Project Board

Issue tracking

A specialized to-do list that also tracks who is on each task and its review before it counts as done.

See it: The Project Board

Todo

The first column of the board, where every new story is created and prioritized.

See it: The Project Board

In Progress

The column for stories someone is working on right now.

See it: The Project Board

QA/Testing

A column you add before Done for stories in final testing before they are merged to main.

See it: The Project Board

Done
