ArrayList Operations

Tap a kid to get it. Then remove one and watch the rest slide over.

ArrayList<String>kids
size: 3
Three kids in a row. The number under a box is its index, and it starts at 0. Tap a box.

The one idea

get, set and remove use positions that start at 0, and removing shifts everything after it down one. add(0, name) shifts them up one instead, set swaps a value in place, and size() follows every add and remove. A position the list does not have stops Java with IndexOutOfBoundsException.
