GitHub Project Board

Your hardware store user stories, moved onto a board on github.com: one card each, in Todo, ready to plan.

What you are building

A GitHub project board named Hardware Store Project, with the columns Todo, In Progress, Testing and Done. Every user story you wrote in the Module 2 exercise becomes a card in Todo: the story is the card title, and the description is a checklist of the tasks that finish it.

No code, no IntelliJ, no repository: everything happens on github.com. You are not building the store, only planning it.

Where people get stuck

  • A table, not columns. Table was picked in the dialog. Make a new project and choose Board.
  • Every card says Draft. That is expected; the workbook keeps them as drafts.
  • Testing sits after Done. Drag it by its name to the left of Done.

The one idea
