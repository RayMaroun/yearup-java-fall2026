Payroll Calculator

Read a csv file line by line, turn every line into an Employee, print what each one earned.

What you are building

A program that opens employees.csv, where each line is id|name|hours-worked|pay-rate. For every line it builds an Employee object and prints the id, the name and the gross pay: hours worked times pay rate.

Nobody types anything: all the data comes from the file. No overtime, no taxes, no writing to a file yet (that is Payroll Calculator 2).

What a finished run looks like

run
10 Dana Wyatt $656.25 20 Ezra Aiden $284.75 30 Brittany Thibbs $660.00 40 Zephaniah Hughes $20.00

Yours may be formatted differently. The four amounts must match.

Where people get stuck

  • Every line splits into single characters. split("|") treats the pipe as "or". Escape it: "\\|".
  • NumberFormatException. A token has a space at the end or start. Trim it before parsing.
  • FileNotFoundException. employees.csv is inside src or a package. It goes at the project root, next to pom.xml.
  • Red under new FileReader. Opening a file can throw: it needs try/catch.
