Search Inventory Map

The same products, this time in a HashMap keyed by id: type a number, get the product, or hear that the store does not carry it.

What you are building

The StoreApp from the HashMap pages. A static HashMap<Integer, Product> named inventory is filled by loadInventory() from inventory.csv, each product stored under its id. main asks for an item number and looks it up with get.

No list, no loop over every product, no search by name. The workbook says "so that users can search for products by name", but its own code keys by id and asks for an item #: the key is the id.

Where people get stuck

  • HashMap<int, Product> does not compile. A map holds objects only: the key type is Integer.
  • NullPointerException on an unknown id. get returns null when the key is missing. Check for null before calling getName.
  • FileNotFoundException. inventory.csv sits at the project root, next to pom.xml, not inside src.
  • Every line splits wrong. The pipe is special in split: it needs escaping, as in the payroll exercise.

The one idea

A map finds a value by its key in one step. When the key is not there, you get null, and the program has to say so.
