Search Engine Logger

A program that keeps a diary: every launch, search and exit goes into logs.txt with the date and time.

What you are building

A loop that asks for search terms until the user types X or x. One method writes a line to logs.txt: the date and time, then what happened. It runs at launch, after each search, and at exit.

It does not search anything; the term only goes into the log. And it never wipes the file: every run adds its lines under the last run's.

Where people get stuck

  • Only the last run is in the file. FileWriter without the append argument true starts the file over each time.
  • Afternoon shows as 02:45. hh is the 12-hour clock; the log uses HH, 0 to 23.
  • Typing x does not stop it. The check only matches X. Compare ignoring case.
  • logs.txt is empty. The writer was never closed, so nothing left the buffer.

The one idea

Append, do not overwrite. A log is only useful when every run adds to it, each line stamped with when it happened.
