Bedtime Stories

Ask which story to read, open that file, and print it back with a number in front of every line.

What you are building

A program that asks for the name of a story file, reads that file one line at a time with a BufferedReader, and prints each line with its line number in front: 1. , 2. and so on.

It does not change the story or write any file. The three stories come from DataFiles.zip; you only read them.

What a finished run looks like

run
Enter the name of a story: goldilocks.txt 1. Goldilocks and the Three Bears 2. 3. Once upon a time a girl named Goldilocks lived in 4. a house at the edge of the woods. In those days ...

The story text is the file's. Your prompt and spacing will differ.

Where people get stuck

  • FileNotFoundException. The .txt files are in src or still in the zip. They belong next to pom.xml.
  • Typed goldilocks. The name needs .txt at the end.
  • Red new FileReader. No try/catch around it. Catch the exception.
  • The blank line has no number. An empty line is still a line: number it too.
