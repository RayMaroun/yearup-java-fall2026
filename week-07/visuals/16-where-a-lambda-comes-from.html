Where a Lambda Comes From

Start from a method you know. Remove what Java can work out, one piece per press.

hand it an employee · tap one

The one idea

A lambda is a method with everything removed that Java can work out by itself. What is left is the parameter, an arrow and the body. It takes the same input and gives the same answer as the method did. It has no name, so you never call it yourself: you hand it to a method such as filter or forEach, and that method calls it.
