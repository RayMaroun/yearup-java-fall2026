What an Interface Is

One set of buttons, three machines. Press a button and watch each one answer.

interface · the buttons

ISwitchable

→same button, every machine

The one idea

An interface is the buttons, not the machine. It lists the methods a class promises to have and gives them no body: void turnOn();. Each class that implements it writes its own body, so the same button does something different on every machine.
