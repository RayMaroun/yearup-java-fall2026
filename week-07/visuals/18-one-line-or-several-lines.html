One Line or Several Lines

The same lambda, short or long. Switch the form and watch which pieces appear.

{ } braces; after each statementreturn

The one idea

One expression: no braces, no return. Several statements: braces around them and a semicolon after each one. Inside braces, a lambda that has to answer must say return. filter waits for true or false, so its lambda returns. forEach waits for nothing, so its lambda never returns anything.
