instanceof With Interfaces

One list, three different objects. Ask each one: can you charge?

the question, asked of one object at a time

thing instanceof Chargeable

things · a List<Object>, it can hold any object

The one idea

instanceof works with interfaces too. thing instanceof Chargeable is true for any object whose class implements Chargeable, whatever that class is. Ask first, then cast to the interface and call its methods.
