The one idea

A package is a folder plus a package statement that matches its path under src/main/java. A class in another package needs an import and must be public; classes in the same package see each other with nothing. Layer-based and feature-based are both valid. Layer-based is the simpler one for a small project, and Raymond accepts either: pick one and keep it for the whole project.
