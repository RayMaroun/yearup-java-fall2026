From the Loop to the Stream

The same search twice: carried by hand in a loop, then flowing through a pipeline.

The loop

you take each employee, test it and add it yourself

the list

for (Employee employee : employees)

the test

if (employee.getAge() < 40)
if

the new list

matchingEmployees.add(employee);

The stream

the data flows through a pipeline, you write only the test

source · data at rest

employees.stream()

transformation · data in transit

.filter(employee -> employee.getAge() < 40)
filter

destination · data at rest

.toList()

Print the new list

fill the new list first, with the loop or the stream above

The loop that prints

for (Employee matchingEmployee : matchingEmployees) { System.out.println(matchingEmployee); }
println

forEach

matchingEmployees.forEach(matchingEmployee -> System.out.println(matchingEmployee));
forEach

The one idea

A stream is a pipeline. The data leaves the source and the work happens while it travels: here filter, with your lambda as the test. toList takes what reaches the end and saves it in a new list, the destination. The loop gives the same result, but you write every step yourself. forEach does the same for the loop that prints.
