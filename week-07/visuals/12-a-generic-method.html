A Generic Method

One method, three calls. Make each call and watch what T becomes.

method · written once

static <T> void displayWithLabel(String label, T value)

the parameters, for this call

String label

T value

what the method does with them

System.out.println(label + ": " + value)

The one idea

A generic method has its own blank. The <T> before the return type declares it, and you never fill it in yourself: on each call the compiler works T out from the argument. One method replaces a whole set of overloads, one per type.
