The one idea

The steps of a stream are a plan. Nothing runs until the last step, the terminal operation. filter keeps or drops, map changes each element, distinct removes repeats. When collect, count or forEach asks for the result, each element travels the pipe in turn. A stream runs once: for a second result, build a new stream from the list.
