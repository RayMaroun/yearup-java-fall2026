stream() source

goes inA collection: a List, for example
comes outA Stream of the same elements; nothing runs yet
kindsource: starts the pipeline
examplenumbers.stream()
resulta stream of 3, 2, 2, 3, 7, 3, 5; numbers is not changed
noteIt starts every pipeline. Each call to stream() gives a fresh stream, so you can start again from the same list.

See it: Stream Methods, One at a Time Source, Transformation, Destination

filter(test) intermediate

goes inA stream, and a lambda that answers true or false for one element
comes outA stream with only the elements for which the lambda said true
kindintermediate: returns a stream, so you can add another step
exampletitles.stream() .filter(t -> t.toLowerCase().contains("halloween")) .collect(Collectors.toList())
result[Halloween, Halloween 2, Halloween 3]
the input[Halloween, Ghost, Halloween 2, Friday the 13th, Twister, Halloween 3]
noteThe elements keep their type and their order; there are just fewer of them.

map(change) intermediate

goes inA stream, and a lambda that turns one element into a new value
comes outA stream with one new value per element, so the same count; the type may change
kindintermediate: returns a stream, so you can add another step
examplenumbers.stream() .map(n -> n * n) .collect(Collectors.toList())
result[9, 4, 4, 9, 49, 9, 25]
the input[3, 2, 2, 3, 7, 3, 5]
type changestitles.stream().map(t -> t.length()) turns a stream of String into a stream of Integer: [9, 5, 11, 15, 7, 11]
upper casenames.stream().map(n -> n.toUpperCase()) turns [alice, bob, charlie, dana] into [ALICE, BOB, CHARLIE, DANA]

See it: Stream Methods, One at a Time Where a Lambda Comes From

sorted() intermediate

goes inA stream whose elements implement Comparable
comes outThe same elements in order, smallest first
kindintermediate: returns a stream, so you can add another step
exampleArrays.asList("Halloween 3", "Halloween", "Halloween 2").stream() .sorted() .collect(Collectors.toList())
result[Halloween, Halloween 2, Halloween 3]
numbersnumbers.stream().sorted() gives [2, 2, 3, 3, 3, 5, 7]
reversesorted(Comparator.reverseOrder()) on [Halloween 3, Halloween, Halloween 2] gives [Halloween 3, Halloween 2, Halloween]
needsComparable. A class without compareTo makes sorted() throw ClassCastException when the stream runs.

See it: Comparable Comparable Sorter game Common Errors

distinct() intermediate

goes inA stream, with or without repeated elements
comes outThe same stream with each value kept once, the first of each
kindintermediate: returns a stream, so you can add another step
examplenumbers.stream() .distinct() .collect(Collectors.toList())
result[3, 2, 7, 5]
the input[3, 2, 2, 3, 7, 3, 5]
with mapnumbers.stream().map(n -> n * n).distinct() gives [9, 4, 49, 25]: square first, then drop the repeats

See it: Stream Methods, One at a Time

forEach(action) terminal

goes inA stream or a collection, and a lambda or method reference to run for each element
comes outNothing (void); the action has run for every element
kindterminal: ends the pipeline, the stream is used up
exampletitles.stream() .filter(t -> t.toLowerCase().contains("halloween")) .forEach(System.out::println)
resultprints three lines: Halloween Halloween 2 Halloween 3
shorterA collection has forEach too: titles.forEach(System.out::println) skips stream().
noteUse it to do something, such as print. To keep the elements, collect them instead.

See it: Stream Methods, One at a Time Where a Lambda Comes From

count() terminal

goes inA stream
comes outA long: how many elements are left
kindterminal: ends the pipeline, the stream is used up
exampletitles.stream() .filter(t -> t.toLowerCase().contains("halloween")) .count()
result3
typeThe result is a long, so store it in a long: long howMany = ...count();

See it: Stream Methods, One at a Time Common Errors

reduce(start, combine) terminal

goes inA stream, a starting value, and a lambda with two parameters: the running result and the next element
comes outOne single value, of the same type as the elements
kindterminal: ends the pipeline, the stream is used up
examplenumbers.stream() .reduce(0, (total, n) -> total + n)
result25
the input[3, 2, 2, 3, 7, 3, 5]
a productArrays.asList(1, 2, 3, 4, 5).stream().reduce(1, (total, n) -> total * n) gives 120; a product starts at 1, not 0
wordswords.stream().reduce("", (acc, w) -> acc + w + " ") on [Potatoes, are, awesome] gives "Potatoes are awesome " with a space at the end, so trim() it

See it: reduce Stream Predictor game

collect(Collectors.toList()) terminal

goes inA stream
comes outA List of the elements that are left
kindterminal: ends the pipeline, the stream is used up
exampletitles.stream() .filter(t -> t.toLowerCase().contains("halloween")) .collect(Collectors.toList())
result[Halloween, Halloween 2, Halloween 3]
into an ArrayListcollect(Collectors.toCollection(ArrayList::new)) when you need an ArrayList
noteThis is the destination of the pipeline: the data is at rest again.

toList() terminal

goes inA stream
comes outA List of the elements that are left, which cannot be changed
kindterminal: ends the pipeline, the stream is used up
exampletitles.stream() .filter(t -> t.toLowerCase().contains("halloween")) .toList()
result[Halloween, Halloween 2, Halloween 3]
workbookThe workbook teaches collect(Collectors.toList()); the demos use the shorter toList(). Both give this list.
read-onlyCalling add on the result throws UnsupportedOperationException.
