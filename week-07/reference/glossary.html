Interfaces

Interface

A named set of features: it lists what a class can do, and every class that implements it has to provide those methods.

public interface Playable { ... }See it: What an Interface Is

Abstract method

A method in an interface with a name and parameters but no body; it is public without saying so.

void stop();See it: What an Interface Is

implements

The keyword that makes a class provide every method of an interface.

public class Speaker implements PlayableSee it: Implementing an Interface

Implementing class

A class that implements an interface; it must write every abstract method with public, or it does not compile.

public void stop() { ... }See it: Implementing an Interface

Several interfaces

A class has at most one parent class but can implement as many interfaces as it needs, separated by commas.

class Phone implements Playable, ChargeableSee it: One Class, Several Interfaces

Interface or abstract class

An abstract class shares fields and code with its children, one parent only; an interface shares only a set of features, as many as you like.

See it: Interface or Abstract Class

Default method

An interface method that comes with a body; a class inherits it and may override it, but does not have to.

default void print() { ... }See it: Default Methods

Unrelated defaults

Two interfaces with the same default method: a class that implements both must override it, or it does not compile.

Playable.super.print();See it: Default Methods

InterfaceName.super

The call that runs the default method of one chosen interface from inside an override.

Chargeable.super.print();See it: Default Methods

@Override

On an interface method, @Override asks the compiler to check the interface really declares that method.

@OverrideSee it: Implementing an Interface

Using an interface

Interface as a type

A variable, parameter or list typed with an interface; it holds any object whose class implements it.

Playable player = new Speaker("Boom");See it: An Interface as a Type

Code to the interface

Declare variables and parameters with the interface type, so the object behind them can change without touching the rest of the code.

List<String> names = new ArrayList<>();See it: Code to the Interface

The List interface

List is an interface; ArrayList and LinkedList are two classes that implement it, so a List variable can hold either.

List<String> names = new LinkedList<>();See it: Code to the Interface

instanceof with an interface

Answers whether an object's class implements the interface; true for every class that does.

thing instanceof ChargeableSee it: instanceof With Interfaces

Cast to an interface

Tells the compiler an object has the interface's methods; ask with instanceof first, or a ClassCastException can follow.

((Chargeable) thing).charge();See it: instanceof With Interfaces

Comparable

The interface a class implements to say how its objects are ordered; sort() and sorted() rely on it.

implements Comparable<Parcel>See it: Comparable

compareTo

The one method of Comparable; it returns a negative number if this comes first, zero if they tie, a positive number if this comes after.

a.compareTo(b)See it: Comparable

Generics

Generics

Classes and methods written once with a type left open, so the same code works for Integer, String or any other type, and the compiler still checks it.

See it: The Need for Generics

Type parameter

The letter in angle brackets that stands for a type not chosen yet; the usual letters are T, K and E.

public class Pair<T>See it: A Generic Class

Type argument

The real type you put in the brackets when you use a generic class; it replaces the type parameter.

Pair<String> twoWordsSee it: A Generic Class

Generic class

A class declared with a type parameter, so each object picks its own type.

public class Pair<T> { ... }See it: A Generic Class

Diamond

The empty angle brackets after new; the compiler fills in the type from the variable on the left.

new ArrayList<>()See it: A Generic Class

Wrapper type

The object version of a primitive; generics take objects only, so use Integer for int and Double for double.

List<Integer>See it: The Need for Generics

Generic method

A method with its own type parameter, written before the return type; each call decides the type.

public static <T> void displayWithLabel(String label, T value)See it: A Generic Method

Bounded type

A type parameter limited with extends, so only that type or its children are accepted.

Duet<T extends Musician>See it: Bounded Types

extends in a bound

In a bound, extends means is a or implements: the argument is the named class, a child of it, or a class that implements the named interface.

<T extends Comparable<T>>See it: Bounded Types

Lambdas and streams

Collection

Data at rest: a list or other group of objects stored in memory, where it can be looped over and changed.

List<Employee> employeesSee it: Loop or Stream

Stream

Data in transit: a flow of elements from a collection through a chain of steps; it does not store anything and does not change its source.

employees.stream()See it: Loop or Stream

Pipeline

A stream from a source, through zero or more transformation steps, to a destination.

titles.stream().filter(...).collect(...)See it: The Stream Pipeline

Intermediate operation

A step that returns another stream, so the chain can go on; nothing runs until a terminal operation ends it.

filter, map, sorted, distinctSee it: The Stream Pipeline

Terminal operation

The step that ends the pipeline and produces a result or an effect; after it the stream cannot be used again.

forEach, count, reduce, collectSee it: The Stream Pipeline

Lambda expression

A short function written in place and passed to a method: parameters, an arrow, a body.

title -> title.length() > 5See it: Anatomy of a Lambda

Lambda body

One expression needs no braces and no return; several statements need { } and an explicit return when a value is wanted.

(a, b) -> { return a + b; }See it: Anatomy of a Lambda

Effectively final

A local variable that is never reassigned after it gets its value; lambdas may read such variables but not change them.

local variables referenced from a lambda expression must be final or effectively finalSee it: Anatomy of a Lambda

Method reference

A shorthand for a lambda that only calls one method.

System.out::printlnSee it: Anatomy of a Lambda

filter

Keeps only the elements for which the lambda returns true.

titles.stream().filter(t -> t.contains("2"))See it: The Stream Pipeline

map

Turns each element into a new value; the stream has the same number of elements.

names.stream().map(n -> n.toUpperCase())See it: The Stream Pipeline

sorted

Puts the elements in order; the element type must implement Comparable.

numbers.stream().sorted()See it: The Stream Pipeline

distinct

Drops repeated elements, keeping the first of each.

numbers.stream().distinct()See it: The Stream Pipeline

forEach

Runs an action once for every element; it returns nothing.

titles.forEach(System.out::println);See it: The Stream Pipeline

count

Returns how many elements are left, as a long.

long howMany = stream.count();See it: The Stream Pipeline

reduce

Folds all the elements into a single value, starting from an initial value and a lambda that combines.

numbers.stream().reduce(0, (total, n) -> total + n)See it: reduce

collect

Gathers the elements into a collection; with Collectors.toList() the result is a List.

stream.collect(Collectors.toList())See it: The Stream Pipeline

toList()

A shorter way to end a stream with a list; the list it gives cannot be changed.

stream.toList()See it: Stream Methods
