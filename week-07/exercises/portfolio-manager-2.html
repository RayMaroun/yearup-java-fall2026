Portfolio Manager 2

A Portfolio class that holds any Valuable and finds the most and the least valuable.

What you are building

Your portfolio-manager code in a new project, portfolio-manager-2. You add a Portfolio class in the finance package: a name and an owner, a list of Valuable, an add method, getValue() for the net value, getMostValuable() and getLeastValuable(). Money is a BigDecimal.

The workbook says to continue in portfolio-manager; here it gets its own project and repository. Nothing in the finance classes changes. The bonus asks main to prompt for new assets.

0 of 8 done

What a finished run looks like

run (one possible)
Portfolio: Retirement Owner: Sam Net value: 41200 Most valuable: House Least valuable: Credit card

Yours will differ: your items, your layout. Work out the net value by hand and compare.

Where people get stuck

  • A bank account will not go into add(). The parameter type is too narrow. It must accept anything that promises getValue().
  • The credit card raises the total. Its value is debt. Look at what its getValue() returns.
  • Most and least valuable give the same item. Check which way you compare, and that you start from the first item in the list.
  • An empty portfolio breaks it. With no items there is nothing to return. Decide what you want to happen.
