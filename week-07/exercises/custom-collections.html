Custom Collections

A generic FixedList that refuses to grow past its maximum size, tested with numbers and dates.

What you are building

One project, custom-collections, with the package com.pluralsight.collection. In it, FixedList<T>: a list of any type of item, but with a maximum number of items. Its constructor takes that maximum, and its add method must not let the list grow past it. A getItems() gives the list back.

In main you test it with different types, and check the add logic with the workbook's numbers and dates.

Yours will differ. A failing line you keep makes the program stop or complain, so comment that line out once you have seen the message.

Where people get stuck

  • The list grows past the maximum. The check goes before the add: compare the current size with maxSize.
  • The dates test will not run. Adding a plain number to a list of dates is refused before the program starts. Read the message, then comment the line out.
  • FixedList<T> shows red in main. The import of the collection package is missing, or the class is in the wrong package.
  • Using int instead of Integer. A type parameter can only be a class. Use the class form, Integer.
