Working With Interfaces

A Person class that implements Comparable, so a list of people sorts itself by last name.

What you are building

One project, working-with-interfaces. This time you do not write the interface: Comparable comes with Java and has one method, compareTo. Person has a first name, a last name and an age. Main builds a list of people and sorts it with Collections.sort.

First you watch the sort fail, and work out why. Then Person implements Comparable and sorts by last name. The bonus breaks ties.

Where people get stuck

  • Collections.sort is red. That is the lesson. Read the message: the list element type has to be Comparable. Fix it in Person, not in main.
  • The compareTo parameter type is wrong. The type between the angle brackets in the header is the type of the parameter.
  • The order looks backwards. compareTo returns a negative, zero or a positive number. Which sign means this person comes first?
  • Comparing last names with a minus or less-than sign. Text is not compared like numbers. Look for a compare method that String already has.

The one idea

Implement the interface, and Java can sort your class. compareTo is your rule; sort uses nothing else.
