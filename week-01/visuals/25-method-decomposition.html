The one idea

Write it once, name it, call it. When the same lines show up again and again, move them into a method, turn the values that change into parameters, and replace each copy with a call. main reads like a list of what happens, and a change in one place reaches every call. The workbook calls this D.R.Y.: Don't Repeat Yourself.
