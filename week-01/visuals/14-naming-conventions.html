Names

Real names from this week

package com.pluralsight;

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        final int DAYS_IN_WEEK = 7;
        int firstNumber = 26;
        boolean isEnrolled = true;
        Scanner myScanner = new Scanner(System.in);
        String firstName = myScanner.nextLine();
        String lastName = myScanner.nextLine();
        String fullName = generateFullName(firstName, lastName);
    }

    public static int addNumbers(int num1, int num2) {
        return num1 + num2;
    }

    public static String generateFullName(String firstName, String lastName) {
        return firstName + " " + lastName;
    }
}

The five shapes

Class

PascalCase

Main, HelloWorld, Scanner

Variable

camelCase

firstNumber, isEnrolled

Method

camelCase()

addNumbers, generateFullName

Constant (final)

UPPER_SNAKE_CASE

DAYS_IN_WEEK

Package

all.lowercase

com.pluralsight

The compiler accepts first_number or main_class. Nobody writes them, so they stand out as wrong.

The one idea

The shape of a name tells the reader what it is before they read the code. The compiler does not enforce these rules, but every Java developer follows them, so a name in the wrong shape reads as a mistake.
