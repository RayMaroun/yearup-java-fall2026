final Constants

A final variable gets its value once, when it is declared, and keeps it. Flip final on and the line that tries to change it no longer compiles.

Main.java

1final String myName = "Raymond";
2System.out.println("Your name is: " + myName);
3myName = myName + " Maroun";
Cannot assign a value to final variable 'myName'
4System.out.println("The full name is: " + myName);

The variable

String myName

A value fixed for every run is a constant, named in UPPER_SNAKE_CASE: final int DAYS_IN_WEEK = 7;

The one idea

final means assign once. The compiler stops any later change before the program ever runs, which is why constants like DAYS_IN_WEEK are declared final.
