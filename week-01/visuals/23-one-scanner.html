The one idea

One Scanner per program, created in main, handed to methods as a parameter. myScanner, potatoScanner and tomatoScanner are different names for one object: Java passes a reference to the Scanner, not a copy of the keyboard. A second new Scanner(System.in) inside a method costs duplicate code, swallowed input and a leaked resource.
