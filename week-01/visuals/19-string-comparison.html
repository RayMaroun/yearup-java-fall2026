== vs .equals

A String variable does not hold the text. It holds an arrow to a String object somewhere in memory. == checks whether two arrows point at the same object; .equals checks whether the characters match. Step through and watch what each one compares.

The one idea

== asks "same object?", .equals asks "same characters?" Text the user types is a new object, so == against a literal is false even when the words match. Two identical literals share one pooled object, which is why == sometimes seems to work. For text you almost always mean .equals, or .equalsIgnoreCase when capital letters should not matter.
