Data Types and Sizes

Every variable in Java has a type, and the type fixes how much memory it gets and what fits in it. Click a type to see its size, its range, and what it holds before you give it a value.

Field = declared in the class, outside any method. Local = declared inside a method, like everything in main.

The one idea

Pick the type for the kind and size of value: whole number, decimal, character, true/false, or text. A declared local variable holds nothing usable until you give it a value; only fields get a default.
