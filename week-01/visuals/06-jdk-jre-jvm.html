Workbook 1c · Section 2-1 · The Java platform

JDK, JRE, JVM

Three names that nest inside each other. The JVM runs bytecode. The JRE wraps it with the class libraries so a program can run. The JDK wraps both with the tools to write one. Pick what you want to do and watch which layer lights up.

One inside the other

JDKJava Development Kit

For writing programs. The tools a developer needs, plus a JRE inside so you can test what you wrote.

javac compilerdebuggerjavadocjar tool
JREJava Runtime Environment

For running programs. The class libraries your code calls, plus the JVM that executes it. No compiler.

java.langjava.utiljava.ioclass libraries
JVMJava Virtual Machine

The engine. Loads a .class file and executes its bytecode. One JVM per kind of computer, so the same .class runs anywhere.

class loaderbytecode interpretergarbage collector

IntelliJ uses the JDK you installed, Amazon Corretto 17. So you already have all three layers.

The one idea

JVM runs bytecode. JRE is the JVM plus the class libraries: enough to run. JDK is the JRE plus the tools: needed to write. Install a JDK and you get all three; install only a JRE and you can run programs but never compile one.
