Centralized vs Distributed

With Git, every computer holds the whole history. GitHub is a copy you share, not the only copy.

Where does the history live?

Switch the mode, then click the server to take it offline.

The one idea

Centralized: one copy of the history, so when the server is down nobody commits. Distributed: a full copy on every computer. Git is distributed. GitHub is the copy you share; commits work offline and you push when you are back. That is why you commit on your machine first and push second.
