Sandwich Shop

A point-of-sale program that asks for a size and an age, then prints what the sandwich costs.

What you are building

A point-of-sale program that asks two questions, the sandwich size and the customer's age, and prints one price.

The new thing is choosing between paths with if / else if / else, twice: once for the size, once for the age. The only arithmetic is a percentage.

0 of 8 done

What a finished run looks like

run
Enter sandwich size (1 for Regular, 2 for Large): 1 Enter age: 16 Cost of sandwich: $4.91 Enter sandwich size (1 for Regular, 2 for Large): 2 Enter age: 70 Cost of sandwich: $7.16 Enter sandwich size (1 for Regular, 2 for Large): 1 Enter age: 30 Cost of sandwich: $5.45

Three separate runs. Your prompts may be worded differently; the amounts are what to check.

Where people get stuck

  • Forgetting "everyone else". A discount that starts at zero already covers it.
  • 10 instead of 0.10. Or subtracting 0.10 dollars instead of 10 percent of the price.
  • "Variable might not have been initialized". A double declared before the if needs a value in every branch; the else makes it complete.
  • 4.905 or 7.160000000000001. The raw double. Format it to two decimals.

The one idea

A condition is a question with a yes or no answer, and the answer picks the path. Set the "everyone else" value first, then let the branches override it.
