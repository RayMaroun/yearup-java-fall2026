In plain English

Make a new Java project named shopping-list, in your workbook-1 folder, with Git turned on. Inside it, one class named ShoppingList with a main method.

The program takes no input and does no math. It prints your shopping list, one item per line, at least ten items. Any items you like.

Then share the project on GitHub, make one more change, and commit and push it.

The one idea

Every Java project you write this year starts the same way: project, package, class, main, run, share. The list is the excuse; the routine is the lesson. Do it slowly this once and it becomes automatic.
