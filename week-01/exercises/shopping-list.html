Shopping List

Your first program: a new project that prints a list of at least ten items, then shared on GitHub.

What you are building

A small Java program that prints your shopping list, one item on each line. Any ten or more items you like.

It asks the user nothing and calculates nothing. It only prints. The point of the exercise is the routine around it: new project, package, class, run, GitHub.

What a finished run looks like

These items are an example. Yours will be different, and that is fine: one item per line is what matters.

Where people get stuck

  • Wrong folder. The Location in the New Project dialog must end in java-development/workbook-1, not Desktop or Downloads.
  • Red class name. The file is ShoppingList.java and the class inside is ShoppingList: same spelling, same capitals.
  • Nothing prints. The lines must be inside main, between its braces. Code outside it never runs.
  • Red line in the editor. Hover it. Most of the time a quote, a parenthesis or a semicolon is missing at the end of that line.

The one idea

Every project this year starts the same way: project, package, class, main, run, share. The list is the excuse; the routine is the lesson. Do it slowly this once and it becomes automatic.
