Method Practice

Four small programs in one project, each one practicing a single thing about methods.

What you are building

One project, four files, each with its own main: calling a void method, reusing one, getting a value back, getting a true or false back.

Nothing is read from the keyboard. Each program only calls its methods and prints.

Where people get stuck

  • void inside println. There is nothing to print. Call it on its own line.
  • Nothing shows. A method that returns does not print. You print what it returns.
  • Wrong program runs. The arrow runs the file whose main you click. Four files, four arrows.
  • Parameter names. Yours to choose; the values come from the call.

The one idea

A method either does something (void) or hands something back (return). The header says which, and the call matches it.
