In plain English

A project named string-application, package com.pluralsight, with two classes: VariableApp and Receipt, each with its own main.

In VariableApp, one variable per question, nine in all, each with the type that fits. Print each inside a sentence.

In Receipt, an item name, a price and a quantity, joined into one sentence. Share on GitHub, commit often, push.

The one idea

Pick the type that matches the data, then join words and values with +. Text, whole numbers, money, one letter, yes or no: each has its own type, and + makes any of them part of a sentence.
