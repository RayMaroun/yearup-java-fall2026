String Application

Two small classes that store values in variables of the right type and print them inside sentences.

What you are building

A program with two classes, VariableApp and Receipt, that prints ten sentences built from variables: your answers, a few facts, and one receipt line.

It asks the user nothing, and the only math is one multiplication in Receipt. The point is choosing the right type for each value and joining text with values.

Where people get stuck

  • Quotes. A single letter goes in single quotes, text in double quotes.
  • Yes or no. Not words to type: Java has a type that holds only true or false. The Data Types page shows it.
  • Words run together. Text and a value are joined with +; put the spaces inside the quotes.
  • Wrong program runs. Each class has its own main: run the one you want with its own green arrow.
