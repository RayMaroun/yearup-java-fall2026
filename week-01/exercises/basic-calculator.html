Basic Calculator

A program that asks for two numbers and an option, then prints one multiplication with its result.

What you are building

A program that asks three questions: two whole numbers, then a choice from a menu of four calculations. It answers with one line: the equation and its result.

The menu is asked but not used yet: it always multiplies. The real calculator comes later this week, with if and switch. The point here is Scanner input and clean prompts.

Your numbers will differ. The option you type does not change the result in this exercise: it always multiplies.

Where people get stuck

  • The option question is skipped. That is the leftover Enter after the last number. The Scanner Buffer page shows it and the fix.
  • InputMismatchException. Letters typed where a number belongs. Read the message, run again.
  • Answer on the next line. System.out.print() versus System.out.println() decides whether the answer goes on the same line.
  • Red Scanner. The import is missing. IntelliJ underlines Scanner in red and offers to add it.

The one idea

Ask, read, use. A prompt tells the user what to type, the right Scanner method reads it, and the leftover Enter is the one thing standing between reading numbers and reading text.
