Payroll Calculator

A program that asks for a name, hours and a pay rate, then prints the gross pay as money.

What you are building

A program that asks three questions (name, hours worked, pay rate) and prints two lines: the name and the gross pay.

New compared to Basic Calculator: reading decimal numbers and printing money with two decimals. The overtime part is optional and uses something not taught yet.

Do these in order

0 of 9 done

What a finished run looks like

run
Enter your name: Dana Enter hours worked: 38.5 Enter pay rate: 20 Name: Dana Gross Pay: $770.00 Process finished with exit code 0

Your wording may differ. The two decimals are the point.

Where people get stuck

  • Odd digits. A plain double prints many decimals or none. Format it to two.
  • Crash on 38,5. nextDouble() wants a dot, not a comma.
  • Half a name. Read the name with nextLine(), or only the first word is kept.
  • Stuck on overtime. It is optional. A working required version pushed to GitHub is the goal.
