Press Start or space. Keys 1 to 3 pick a name.

variable, method = camelCase · constant = UPPER_SNAKE_CASE · class = PascalCase · project = lower-dashes · package = lower.dots

The one idea

The shape of a name tells you what it is. PascalCase is a class, ALL_CAPS is a constant, camelCase is a variable or a method. No leading digit, no keyword, no spaces, and the name says what it holds.
