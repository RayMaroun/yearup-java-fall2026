Week 1 · Reference

Common Errors

The messages you will meet this week, word for word. Read the first line of the message: it usually names the fix.

Show
Compile

Missing semicolon

See it
java: ';' expected

Every statement ends with a semicolon, and javac stops at the first line that does not.

FixAdd ; at the end of the line the message points to.

Before
System.out.println("Hello")
After
System.out.println("Hello");
Compile

Misspelled method name

java: cannot find symbol
  symbol:   method pintln(java.lang.String)
  location: variable out of type java.io.PrintStream

Java is exact: there is no method called pintln, so the compiler cannot find it.

FixCorrect the spelling; let IntelliJ autocomplete names as you type.

Before
System.out.pintln("Hi");
After
System.out.println("Hi");
Compile

Misspelled or undeclared variable

java: cannot find symbol
  symbol:   variable nmae
  location: class Main

You used a variable name that was never declared, often a typo or a wrong capital letter.

FixUse the exact name from the declaration (name and Name are different).

Before
String name = "Dana";
System.out.println(nmae);
After
String name = "Dana";
System.out.println(name);
Compile

Missing closing brace

java: reached end of file while parsing

The file ended while a { was still open; here the method is closed but the class is not.

FixAdd the missing }; click a brace and IntelliJ highlights its partner.

Before
public class Main {
    public static void main(String[] args) {
        System.out.println("Hi");
    }
After
public class Main {
    public static void main(String[] args) {
        System.out.println("Hi");
    }
}
Compile

Text in single quotes

java: unclosed character literal

Single quotes hold one char; a String needs double quotes.

FixUse "..." for text, 'x' only for a single character.

Before
String name = 'Dana';
After
String name = "Dana";
Compile

Assigning to a final constant

See it
java: cannot assign a value to final variable DAYS_IN_WEEK

A final variable gets its value once and can never be changed.

FixRemove the reassignment, or drop final if the value really must change.

Before
final int DAYS_IN_WEEK = 7;
DAYS_IN_WEEK = 8;
After
final int DAYS_IN_WEEK = 7;
int daysOff = 2;
Compile

double into an int

See it
java: incompatible types: possible lossy conversion from double to int

An int cannot hold the decimal part, so Java refuses to narrow without being told.

FixCast on purpose with (int), or store the result in a double.

Before
double price = 19.99;
int dollars = price;
After
double price = 19.99;
int dollars = (int) price;
Compile

float literal without f

See it
java: incompatible types: possible lossy conversion from double to float

A decimal literal like 2.2 is a double by default, which is bigger than a float.

FixAdd f to the literal: 2.2f.

Before
float weight = 2.2;
After
float weight = 2.2f;
Compile

String into an int

See it
java: incompatible types: java.lang.String cannot be converted to int

nextLine() returns a String, and a String does not fit in an int variable.

FixUse the Scanner method that returns the type you want: nextInt().

Before
int age = scanner.nextLine();
After
int age = scanner.nextInt();
Compile

Scanner without the import

See it
java: cannot find symbol
  symbol:   class Scanner
  location: class Main

Scanner lives in java.util, and the file never imported it.

FixAdd import java.util.Scanner; under the package line (or Alt+Enter in IntelliJ).

Before
package com.pluralsight;

public class Main {
After
package com.pluralsight;

import java.util.Scanner;

public class Main {
Compile

Variable used before it has a value

java: variable total might not have been initialized

A local variable was declared but not given a value before it was read.

FixGive it a starting value when you declare it.

Before
int total;
System.out.println(total);
After
int total = 0;
System.out.println(total);
Compile

Method that forgets to return

See it
java: missing return statement

The signature promises an int back, but the body never returns one.

FixEnd with return, or make the return type void if nothing comes back.

Before
public static int add(int a, int b) {
    int sum = a + b;
}
After
public static int add(int a, int b) {
    int sum = a + b;
    return sum;
}
Compile

Calling a method without its argument

See it
java: method displayMenu in class Main cannot be applied to given types;
  required: java.util.Scanner
  found:    no arguments
  reason: actual and formal argument lists differ in length

The method's parameter list asks for a Scanner and the call passed nothing.

FixPass what the signature requires, in the same order.

Before
displayMenu();
After
displayMenu(scanner);
Compile

Class name does not match the file

java: class HelloWorld is public, should be declared in a file named HelloWorld.java

A public class must live in a .java file with exactly the same name.

FixRename the file or the class with Shift+F6 so they match.

Before
// Hello.java
public class HelloWorld {
After
// HelloWorld.java
public class HelloWorld {
Runtime

Wrong input type for Scanner

See it
Exception in thread "main" java.util.InputMismatchException
	at java.base/java.util.Scanner.throwFor(Scanner.java:939)
	...
	at com.pluralsight.Main.main(Main.java:9)

nextInt() got text it cannot read as a whole number, like 25.5 or hello.

FixMatch the method to the input: nextDouble() for decimals, and say the format in the prompt.

Before
System.out.print("Price: ");
int price = scanner.nextInt();
After
System.out.print("Price: ");
double price = scanner.nextDouble();
Runtime

nextLine() skipped after nextInt()

See it

No error. Console:

Enter your age: 25
Enter your name: Hello, !

nextInt() leaves the Enter key in the buffer, and nextLine() reads that empty line at once.

FixCall scanner.nextLine(); once after nextInt() to clear the leftover line.

Before
int age = scanner.nextInt();
String name = scanner.nextLine();
After
int age = scanner.nextInt();
scanner.nextLine();
String name = scanner.nextLine();
Runtime

== on Strings

See it

No error. The user typed Dana, console:

(nothing printed)

== asks whether two variables are the same object, not whether the text matches.

FixCompare text with .equals() or .equalsIgnoreCase().

Before
if (name == "Dana") {
After
if (name.equals("Dana")) {
Runtime

Integer division drops the decimals

See it

No error. Console:

3.0

Both operands are int, so 10 / 3 is 3 before it ever reaches the double.

FixMake one operand a double: 10.0 / 3 or (double) a / b.

Before
double result = 10 / 3;
After
double result = 10.0 / 3;
Runtime

Dividing an int by zero

See it
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at com.pluralsight.Main.main(Main.java:12)

Integer division by 0 has no answer, so the program stops at that line.

FixCheck the divisor before dividing.

Before
int each = total / people;
After
if (people != 0) {
    int each = total / people;
}
Runtime

Numbers glued instead of added

See it

No error. Console:

Score: 1020

+ runs left to right; once a String is on the left, every + joins text.

FixPut the math in parentheses so it runs first.

Before
System.out.println("Score: " + a + b);
After
System.out.println("Score: " + (a + b));
Runtime

switch without break

See it

No error. day is 1, console:

Monday
Tuesday

In the traditional form, a matching case keeps running into the next one until a break.

FixEnd each case with break;, or use the arrow form, which never falls through.

Before
case 1:
    System.out.println("Monday");
case 2:
    System.out.println("Tuesday");
After
case 1:
    System.out.println("Monday");
    break;
case 2:
    System.out.println("Tuesday");
    break;
Runtime

print instead of println

No error. Console:

HelloWorldJava

print adds no line break, so each output starts where the last one ended.

FixUse println when each value should be on its own line.

Before
System.out.print("Hello");
System.out.print("World");
After
System.out.println("Hello");
System.out.println("World");
Runtime

Scanner closed, or a new Scanner per method

See it
Exception in thread "main" java.lang.IllegalStateException: Scanner closed

A method closed the Scanner on System.in, and every later read fails.

FixCreate one Scanner in main, pass it to methods, never create or close it inside them.

Before
static int getAge() {
    Scanner s = new Scanner(System.in);
    int age = s.nextInt();
    s.close();
    return age;
}
After
static int getAge(Scanner scanner) {
    return scanner.nextInt();
}
Runtime

main written wrong

Error: Main method not found in class com.pluralsight.Main, please define the main method as:
   public static void main(String[] args)
or a JavaFX application class must extend javafx.application.Application

The JVM only starts at the exact signature main(String[] args); no green Run arrow appears without it.

FixType psvm + Tab in IntelliJ to get the correct line.

Before
public static void main(String args) {
After
public static void main(String[] args) {
IntelliJ and Maven

Red underline, nothing runs

Hover the red squiggle:

Cannot resolve symbol 'scanner'

IntelliJ found the problem before you ran; the tooltip and the Problems tab say what it is.

FixHover the red line or open the Problems tab at the bottom, then fix the first entry.

Before
int age = scanner.nextInt();
After
Scanner scanner = new Scanner(System.in);
int age = scanner.nextInt();

See it

Yellow bar above the editor:

Project JDK is not defined   Setup SDK

IntelliJ has no JDK for this project, so even String shows in red.

FixClick Setup SDK, or File > Project Structure > Project, and pick corretto-17.

Before
SDK: <No SDK>
After
SDK: corretto-17 Amazon Corretto 17

The pom asks for Java 17 but the project is set to an older JDK.

FixFile > Project Structure > Project: set SDK to corretto-17.

Before
SDK: 11
After
SDK: corretto-17
IntelliJ and Maven

Maven project not loaded

See it

Notification:

Maven build scripts found   Load

IntelliJ has not read the pom.xml, so src/main/java is not blue and Run is missing.

FixClick Load, or right-click pom.xml and choose Add as Maven Project.

Before
src/main/java   (plain folder)
After
src/main/java   (blue source root)
IntelliJ and Maven

File in the wrong folder for its package

See it
Package name 'com.pluralsight' does not correspond to the file path ''

The package line must match the folders under src/main/java.

FixMove the file into com/pluralsight (Alt+Enter offers to do it).

Before
src/main/java/Main.java
After
src/main/java/com/pluralsight/Main.java

Name and email not set

See it

Dialog on your first commit:

Git User Name Is Not Defined

Every commit records who made it, and Git does not know you yet.

FixFill in Name and Email, tick Set properties globally, then commit.

Before
Name:  (empty)
Email: (empty)
After
Name:  Your Name
Email: the one on your GitHub account

GitHub login failed

See it
fatal: Authentication failed for 'https://github.com/your-name/hello-java.git/'

IntelliJ is not logged in to GitHub, or the saved login expired.

FixSettings > Version Control > GitHub > + > Log In via GitHub, then push again.

Before
GitHub: no accounts
After
GitHub: your-name  (github.com)
Git

Unregistered Git folder

See it
Unregistered VCS root detected
The directory ... is under Git, but is not registered in the Settings.

IntelliJ found a Git repository it is not tracking yet, so commits may miss it.

FixClick Add root; one project folder should be one repository.

Before
Commit panel: no changes shown
After
Commit panel: your changed files
