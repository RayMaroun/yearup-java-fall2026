Glossary

The words of the week, one sentence each. Type a word and the list narrows as you go.

Filter

Java platform

JDK

The Java Development Kit: the compiler and tools for writing programs, with a JRE inside so you can run them.

See it: JDK, JRE, JVM

JRE

The Java Runtime Environment: the JVM plus the class libraries, enough to run a program but not to compile one.

See it: JDK, JRE, JVM

JVM

The Java Virtual Machine: the engine that loads a .class file and runs its bytecode, one per kind of computer.

See it: JDK, JRE, JVM

Source code

The human-readable Java you write, saved in a .java file whose name matches its public class.

HelloWorld.javaSee it: Compile, Bytecode, JVM

Compiler (javac)

The tool that checks your source code for syntax errors and turns it into bytecode.

javac HelloWorld.javaSee it: Compile, Bytecode, JVM

Bytecode

The compiled form of your program, stored in a .class file: not machine code, the JVM runs it.

HelloWorld.java -> javac -> HelloWorld.classSee it: Compile, Bytecode, JVM

Class

The container every piece of Java code lives in; the file name must match the public class name.

public class HelloWorld { }

main method

The entry point of a program: the JVM starts running here, so the signature must be exact.

public static void main(String[] args)

Package

A folder-like grouping of classes, lowercase with dots, declared on the first line of the file.

package com.pluralsight;See it: Maven Project Structure

import

A line at the top of a file that lets you use a class from another package by its short name.

import java.util.Scanner;

Types and variables

Variable

A named slot in memory that holds one value of a declared type.

int count = 10;See it: Data Types and Sizes

Data type

Tells Java what kind of value a variable holds and how much memory to set aside for it.

See it: Data Types and Sizes

Primitive type

One of the 8 built-in types that store a simple value directly: byte, short, int, long, float, double, boolean, char.

int n = 5; double d = 9.99; boolean ok = true; char c = 'A';See it: Data Types and Sizes

Literal

A value written directly in code; a decimal literal is a double unless you add f to make it a float.

42 3.14 2.2f 'A' "hi"See it: Data Types and Sizes

String

A reference type that holds text; compare two Strings with .equals(), never ==.

String name = "Ray";See it: == vs .equals

final (constant)

Makes a variable unchangeable once assigned; by convention its name is in UPPER_SNAKE_CASE.

final double TAX_RATE = 0.0825;See it: final Constants

Naming conventions

camelCase for variables and methods, PascalCase for classes, UPPER_SNAKE_CASE for constants.

int itemCount; class ShoppingList; MAX_ITEMSSee it: Naming Conventions

Widening

Java converts a smaller type to a larger one for you, because nothing can be lost.

int x = 10; double y = x; // 10.0See it: Widening, Narrowing, Casting

Narrowing / casting

Converting to a smaller type needs a cast in parentheses, and the decimal part is cut off.

int whole = (int) 9.99; // 9See it: Widening, Narrowing, Casting

Local variable

A variable declared inside a method; it is created when the method is called and discarded when it ends.

See it: Method Call Stack

Operators

Expression

Values, variables and operators that Java evaluates to one value.

(count * unitPrice) * (1 + taxRate)

Arithmetic operators

Add, subtract, multiply, divide and remainder; * and / are done before + and -.

int sum = 10 + 3 * 2; // 16See it: Integer Division and Modulo

Integer division

When both sides are int, / drops the decimal part instead of rounding.

10 / 3 // 3, not 3.33See it: Integer Division and Modulo

Modulo (%)

Gives the remainder after division, useful for even or odd checks.

10 % 3 // 1See it: Integer Division and Modulo

Assignment (=)

Stores the value on the right into the variable on the left; it does not mean equals.

x = 5;

Compound assignment

Shorthand that combines math with assignment: x += 3 means x = x + 3.

total += price;

Increment / decrement

Adds or subtracts 1; prefix (++x) changes first, postfix (x++) uses the old value first.

int a = ++x; int b = x++;See it: Pre and Post Increment

Concatenation

+ joins text when either side is a String, and Java reads it left to right.

"Total: " + 1 + 2 // Total: 12See it: Concatenation vs Addition

Comparison operators

Compare two values and produce true or false.

age >= 18

Logical operators

&& needs both sides true, || needs one, ! flips true and false.

age >= 18 && hasIdSee it: Logical Operators

Conditional operator

A one-line if/else that picks one of two values.

String s = age >= 18 ? "adult" : "minor";

Math class

Built-in math methods you call on the class itself.

Math.max(a, b) Math.sin(Math.toRadians(degrees))

Input and output

System.out.println()

Prints a value to the console and moves to a new line; print() stays on the same line.

System.out.println("Hello");

printf

Prints with placeholders: %d whole number, %s text, %.2f two decimals, %n new line.

System.out.printf("Total: %.2f%n", 9.5);See it: printf Format Specifiers

Scanner

Reads what the user types; create one in main and pass it to the methods that need input.

Scanner scanner = new Scanner(System.in);See it: Scanner Methods

System.in

The keyboard input stream that you hand to a Scanner.

nextLine() / nextInt() / nextDouble()

nextLine() reads a whole line of text; nextInt() and nextDouble() read one number and stop.

int age = scanner.nextInt();See it: Scanner Methods

Input buffer

Where typed input waits; nextInt() leaves the Enter behind, so add one extra nextLine() before reading text.

scanner.nextInt(); scanner.nextLine();See it: Scanner Buffer

Line separator (CRLF)

The invisible characters Enter puts in the buffer, carriage return plus line feed on Windows.

See it: Scanner Buffer

One Scanner

Create a single Scanner in main and pass it as a parameter, rather than one per method.

askName(scanner);See it: One Scanner, Many Methods

Decisions

Condition

An expression that is true or false, written in parentheses after if.

(temperature > 100)See it: if / else Path

if

Runs its block only when the condition is true; always use curly braces.

if (age >= 18) { ... }See it: if / else Path

if / else

Adds a block that runs when the condition is false, so exactly one of the two runs.

if (ok) { ... } else { ... }See it: if / else Path

else if

Chains several conditions; Java runs the first block whose condition is true and skips the rest.

else if (score >= 80) { ... }See it: if / else Path

.equals()

Compares the text of two Strings; == only checks whether they are the same object.

if (answer.equals("yes")) { ... }See it: == vs .equals

switch

Compares one value against a list of cases; Java 17 has a traditional form and an arrow form.

switch (command) { ... }See it: switch, Both Forms

case / break / default

case marks a value to match, break leaves the switch, default runs when nothing matches.

case "add": total++; break;See it: switch, Both Forms

Fall-through

Without break, a traditional switch keeps running into the next case, a common bug.

See it: switch, Both Forms

Arrow switch

Uses -> instead of : and break; each case runs only its own code, so there is no fall-through.

case "add" -> total++;See it: switch, Both Forms

Methods

Method

A named block of code that does one task and can be called again and again.

public static int add(int a, int b) { return a + b; }See it: Method Signature

Method signature

The method name plus its parameter list, which is how Java tells methods apart.

add(int, int)See it: Method Signature

Parameter vs argument

A parameter is the variable in the method header; an argument is the value you pass in the call.

add(3, 4) // 3 and 4 are argumentsSee it: Method Signature

Return type

The type of value a method sends back, written before its name; void means nothing comes back.

public static double calcTax(double amount)See it: Method Signature

return

Sends a value back to the caller and leaves the method at once.

return amount * TAX_RATE;

static

Marks a method that belongs to the class, so you call it without creating an object; all week 1 methods are static.

Method call

Runs a method by name with its arguments; control jumps in and comes back when it returns.

double tax = calcTax(100.0);See it: Method Call Stack

Call stack

The stack of running methods: a call pushes a frame, a return pops it, and main sits at the bottom.

See it: Method Call Stack

DRY

Don't Repeat Yourself: when the same code appears twice, move it into one method.

See it: Repeated Code to One Method

Git and GitHub

Version control

A system that records every change to your files so you can see history and go back.

See it: Version Control Timeline

Distributed version control

Every developer has a full copy of the history on their own machine, not only the server.

See it: Local vs Remote Repository

Git

The version control tool you use through IntelliJ: commit panel, push, pull, file colors.

See it: Git Through IntelliJ

Repository (repo)

A project folder tracked by Git, with its full history kept in a hidden .git folder.

See it: Local vs Remote Repository

Commit

A saved snapshot of your project with a message that says what changed.

See it: Git Through IntelliJ

Push / pull

Push sends your local commits to the remote; pull brings new commits down.

See it: Local vs Remote Repository

Remote (origin)

The copy of your repository on a server; the default one is named origin.

See it: Local vs Remote Repository

Branch

An independent line of work; the default branch is main.

GitHub

The website that hosts your repositories; IntelliJ's Share Project on GitHub creates one for you.

See it: Git Through IntelliJ

Maven project

Maven

See it: Maven Project Structure

pom.xml

Maven's configuration file at the project root: names, version and libraries.

See it: Maven Project Structure

src/main/java

The folder where your .java files live, organized by package.

See it: Maven Project Structure

src/test/java

The folder for test code that checks your main code works.

See it: Maven Project Structure

GroupId / ArtifactId

GroupId names your organization (com.pluralsight); ArtifactId names the project.

See it: Maven Project Structure
