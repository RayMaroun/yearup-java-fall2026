Inheritance basics

Inheritance

A new class built on an existing one, so it gets the existing fields and methods without copying them.

public class Dog extends Animal { ... }See it: The Duplication Problem

Generalization

Moving what two or more classes share up into one parent class, so each child keeps only what is its own.

See it: The Duplication Problem

extends

The keyword that makes one class the child of another.

public class Caveman extends HumanSee it: What a Child Inherits

Is-a

The test for inheritance: if the sentence "a Caveman is a Human" is true, Caveman can extend Human; the arrow points from child to parent.

See it: Is-A

Has-a

A class that holds another as a field, such as a House with an address; it is not inheritance.

private String address;See it: Is-A or Has-A game

Parent class

The class being extended; also called the super class or base class.

public class Animal { ... }See it: What a Child Inherits

Child class

The class that extends another; also called the sub class or derived class.

public class Dog extends Animal { ... }See it: What a Child Inherits

Inherited member

A field or method written in the parent that a child object has, even though the child never declares it.

dog.setName("Potato"); // written in AnimalSee it: What a Child Inherits

Access

private

Reachable only inside its own class; a child inherits a private field but cannot touch it directly.

private String name;See it: Private, Protected, Public

protected

Reachable inside its own class, in child classes, and in the same package; not from other classes outside the package.

protected String favoriteFood;See it: Private, Protected, Public

public

Reachable from any class.

public String getName()See it: Private, Protected, Public

Constructors

super(...)

A call to a parent constructor from inside a child constructor; it has to be the first statement.

super(name, age);See it: super With Arguments

Constructor chain

The order constructors run: the parent constructor first, then the child's, all the way up.

new Dog("Lucky", 15, "Doberman")See it: The Constructor Chain

Default super call

The super() Java adds for you when a child constructor does not call one; it fails if the parent has no constructor without parameters.

super(); // added for youSee it: The Constructor Chain

Overriding and polymorphism

Override

A child method with the same name and parameters as a parent method, replacing the inherited version for objects of the child.

public void eat() { ... } // in CavemanSee it: Method Overriding

@Override

The annotation that asks the compiler to check the parent really has that method, so a typo becomes an error.

@OverrideSee it: The @Override Annotation

Overriding vs overloading

Overriding repeats the parent's signature to replace it; overloading uses the same name with different parameters and adds a second method.

See it: Override Detector game

Polymorphism

One call, many results: the same eat() runs a different version depending on the real object.

person.eat();See it: Method Overriding

Base class reference

A variable of the parent type holding a child object; the variable decides what you may call and the object decides what runs.

Human human1 = new Caveman(...);See it: Base Class References

Heterogeneous collection

One list typed with the parent class that holds objects of several child types.

ArrayList<Human> people = new ArrayList<>();See it: One List, Many Types

instanceof

The operator that answers whether an object is of a type; true for that class and for every parent above it.

person instanceof CavemanSee it: instanceof and Downcasting

Downcast

A cast that tells the compiler a parent variable really holds a child object, so you can call the child's own methods.

Caveman c = (Caveman) person;See it: instanceof and Downcasting

ClassCastException

The run time error when a cast promises a type the object is not.

ModernPerson m = (ModernPerson) firstHuman;See it: instanceof and Downcasting

getClass().getSimpleName()

Asks an object for its real class and returns the short name as a String.

person.getClass().getSimpleName() // "Caveman"See it: instanceof and Downcasting

Object

The parent of every class, even when you write no extends; it gives all objects getClass(), toString() and equals().

me instanceof Object // trueSee it: Base Class References

toString()

The Object method that println calls to turn an object into text; classes override it for a readable line.

@Override public String toString() { ... }

Abstraction

Abstract class

A class marked abstract because the idea is too general to build; you can extend it but never use new on it.

public abstract class Asset { ... }See it: Abstract Classes

Abstract method

A method with a signature and no body that every concrete child has to override.

public abstract BigDecimal getValue();See it: Abstract Methods

Concrete class

A normal class with every method finished, so new works on it.

public class House extends Asset { ... }See it: Abstract or Concrete game

Concrete method

A method with a body; an abstract class can hold some and its children inherit them.

public void printMessage() { ... }See it: Abstract Methods

Drawing it

Class diagram

A drawing with one box per class and lines between them, in three bands: name, attributes, methods.

See it: Class Diagram Reference

Inheritance arrow

The line with a hollow triangle at the parent end; it is read as "is a".

See it: Reading a Class Diagram
