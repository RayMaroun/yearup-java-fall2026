Overriding and @Override 5a · 2-1

parent versionpublic class Human { public void eat() { System.out.println("I am a Human and I am Hungry!"); } }
child versionpublic class Caveman extends Human { @Override // the compiler checks Human really has eat() public void eat() { System.out.println("Me Hunt Lion and Eat!"); } }
same signaturesame name, same parameters: the child version replaces the inherited one
not an overridepublic void eat(int n) { } // overload: a second method, the parent eat() stays
a typo@Override public void eet() { } // error: method does not override or implement a method from a supertype
no annotationpublic void eet() { } // compiles: quietly a new method, the parent eat() still runs
not weakervoid eat() { } // error: attempting to assign weaker access privileges; was public
child extraspublic void run() { } // only in Caveman: not in Human
