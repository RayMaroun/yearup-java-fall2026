Assets Manager

An Asset parent, a House and a Vehicle child that each work out their own value, and one list that holds them all.

What you are building

One project, assets-manager. Asset has a description, a date acquired and an original cost, and a getValue(). House and Vehicle extend it and override getValue() with their own rules. Main puts several of each in one ArrayList of Asset and loops through it.

No menu and no user input. The workbook warns that this is a hugely simplified academic example. Money is a BigDecimal, not a double.

Where people get stuck

  • Value is the same for every asset. The loop calls getValue() on an Asset, and the object's own class decides which version runs. Did House and Vehicle override it?
  • double instead of BigDecimal. The cost and every value are BigDecimal, built from text. Use its methods, not the + and * signs.
  • Cannot call getAddress() on an Asset. The list type only knows Asset's methods. Test with instanceof first, then downcast.
  • Vehicle value off. The percentage is taken every year from what the car is still worth, so the same step repeats once per year of age. Check a 2 year old car by hand first, then a brand new one and a very old one.
