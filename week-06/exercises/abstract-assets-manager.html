Abstract Assets Manager

Your assets code in a new project: Asset becomes abstract, then a Cash class joins.

What you are building

A copy of assets-manager in a new project, abstract-assets-manager. In Asset the class becomes abstract and getValue() becomes an abstract method. Then a new class, Cash, extends Asset: the cash you stash away under your mattress.

No new rules for houses or vehicles. The workbook asks you questions here: write your answers down as you go, they are part of the exercise.

Where people get stuck

  • new Asset(...) is red. That is the answer to the workbook question. Read the message, write it down, then take the line out.
  • Cash is red as soon as you write it. Read the message. It names what the class must do and what it must pass up. Write down your options.
  • The vehicles stopped compiling. Check the signature of getValue() in Asset and in each child. They have to match.
  • Copied the folder instead of a new project. The new project needs its own repository. Start with File > New > Project and paste the code in.
