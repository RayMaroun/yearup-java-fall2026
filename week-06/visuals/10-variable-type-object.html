The one idea

The variable type is fixed, and it is what the compiler checks. The object keeps its own class. A variable of the parent type can refer to any child object: Human h accepts a Human, a Caveman or a ModernPerson. Never the other way around: a Caveman variable cannot refer to a plain Human.
