instanceof and Downcasting

Ask each object if it is a Caveman. Then cast it and see what Java does.

The one idea

Test first, then cast. A Human variable only reaches what Human has. instanceof asks the object what it really is, and a downcast such as (Caveman) person gives you a Caveman variable for the same object, so run() opens up. Cast an object that is not a Caveman and the program stops with ClassCastException.
