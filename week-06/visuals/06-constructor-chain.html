Each constructor prints one line. Nothing has run yet: which line do you expect first?

The one idea

Parent first, child after. new Dog() enters Dog's constructor, but its first line is super(), so Animal's constructor body runs to the end before Dog's own lines do. A dog is an animal first: that part is built first.
