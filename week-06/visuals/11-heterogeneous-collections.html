One List, Many Types

One list, three kinds of Human. Ask each one to eat, one press at a time.

List<Human>peoplesize 3

The one idea

A list typed with the parent class can hold any of its children. A List<Human> takes a Human, a Caveman and a ModernPerson, because each one is a Human. The loop makes the same call on every element, and each object answers with the eat() of its own class.
