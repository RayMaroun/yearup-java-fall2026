break and continue 2a · 3-1

breakleave the loop now
continueskip the rest of this pass, go to the next one
break examplefor (int i = 1; i <= 10; i++) { if (i % 3 == 0) { break; } sum += i; } // sum is 3: only 1 and 2, the loop ends at 3
continue examplefor (int i = 1; i <= 10; i++) { if (i % 3 == 0) { continue; } sum += i; } // sum is 37: 3, 6 and 9 skipped
without continueif (i % 3 != 0) { sum += i; } // same 37
