Filter

Strings

String method

A built-in action you call on a String with a dot; it reads the text or returns a new String.

"New Mexico".toUpperCase()See it: String Methods

Escape character

A backslash that gives the next character a special meaning: \" a quote, \n a new line, \t a tab.

"Raymond \"Maroun\""See it: String Methods

Immutable

A String can never change; every method that seems to change it returns a new String instead.

city = city.toUpperCase();See it: Strings Are Immutable

Index (in a String)

The position of a character, counted from 0, so the last one is at length() - 1.

"ACME".charAt(0) // 'A'See it: String Methods

Substring

A piece of a String, from a start index up to, but not including, an end index.

"ACME-12213".substring(0, 4) // ACMESee it: String Methods

Chaining

Calling a method on the result of another method, read left to right.

typedName.trim().toUpperCase()See it: String Methods

Empty string

A String with no characters at all; a String of spaces is not empty until you trim it.

"".isEmpty() // trueSee it: String Methods

equals()

Compares two Strings character by character and returns true when the text matches.

language.equals(builtLanguage)See it: Comparing Strings

equalsIgnoreCase()

Like equals(), but upper and lower case count as the same letter.

"YES".equalsIgnoreCase("yes") // trueSee it: Comparing Strings

Reference equality (==)

On Strings, == asks whether both variables point to the same object, not whether the text is the same.

String built = prefix + "va"; built == "Java" // falseSee it: Comparing Strings

Converting

Parse

To read text and turn it into a value of another type, like a number or a date.

Integer.parseInt("12") // 12See it: String to Number

Integer.parseInt() / Double.parseDouble()

Turn text like "12" or "4.99" into an int or a double; anything else in the text throws NumberFormatException.

double price = Double.parseDouble("4.99");See it: String to Number

Delimiter

The character that separates the fields of a line of text, such as | or a comma.

"204|Ground Coffee (2 lb)|30|13.49"See it: String to Number

split()

Cuts a String at every delimiter and returns the pieces as a String array.

String[] tokens = record.split(Pattern.quote("|"));See it: String to Number

Regular expression

A pattern that describes what text looks like; split() reads its argument as one, so some characters are special.

record.split("\\|")See it: String to Number

Pattern.quote()

Makes split() treat a character as plain text, not as a regular expression symbol.

import java.util.regex.Pattern;See it: String to Number

LocalDate

A date with no time of day; it knows its day of the week and can be compared and formatted.

LocalDate start = LocalDate.parse("2026-10-12");See it: String to Date

ISO 8601

The international date format yyyy-MM-dd, the only one LocalDate.parse() reads without help.

2026-10-12See it: String to Date

DateTimeFormatter

Describes a date layout with letters like MM, dd and yyyy, to parse text in that layout or to print a date that way.

DateTimeFormatter.ofPattern("MM/dd/yyyy")See it: String to Date

StringBuilder

StringBuilder

A changeable sequence of characters you add to in place, then turn into a String at the end.

StringBuilder tools = new StringBuilder();See it: StringBuilder

Mutable

Able to change after it is created; a StringBuilder is mutable, a String is not.

See it: StringBuilder

append()

Adds text or a number to the end of a StringBuilder and returns the same builder, so calls can be chained.

receipt.append("Coffee x ").append(2);See it: StringBuilder

insert()

Puts text into a StringBuilder at an index; index 0 is the front.

tools.insert(0, "Course tools: ");See it: StringBuilder

toString() on a builder

Hands back the finished text as a real String, since a StringBuilder is not a String.

String toolList = tools.toString();See it: StringBuilder

Classes and objects

Object-oriented programming

Organizing a program into classes that package data with the methods that work on that data.

See it: Class vs Object

Class (blueprint)

The blueprint that says what data an object holds and what it can do; it lives in a .java file of the same name.

public class Person { ... }See it: Class vs Object

Object (instance)

One thing built from a class, with its own copy of every field.

Person student = new Person("Natalie", 37);See it: Class vs Object

Instantiate

To create an object from a class with new.

instructor = new Person("Raymond", 35);See it: What new Does

new

Makes room for a new object, runs the constructor, and gives back a reference to the object.

new Person(name, age)See it: What new Does

Field (instance variable)

A variable declared in the class, outside every method; each object keeps its own value.

private int energy;See it: Class vs Object

State

The current values of an object's fields; two Person objects can be in different states.

instructor.getEnergy() // 50 after work(5)See it: Class vs Object

Constructor

The code that runs once when an object is created; same name as the class, no return type.

public Person(String name, int age) { ... }See it: What new Does

this

Means "this object"; this.name is the field, name alone is the parameter.

this.name = name;See it: What new Does

Encapsulation

Hiding an object's data inside the class and letting other code reach it only through methods.

See it: Encapsulation

public / private

Access modifiers: public members can be used from any class, private ones only inside their own class.

private String name; public String getName()See it: Encapsulation

Package-private

What you get with no modifier: visible to every class in the same package, hidden from other packages.

int age;See it: Encapsulation

Getter

A public method starting with get that returns the value of a private field.

public int getAge() { return this.age; }See it: Encapsulation

Setter

A public method starting with set that changes a private field; leave it out to make the field read only.

public void setAge(int age) { this.age = age; }See it: Encapsulation

Method (action)

A method that does something with the object's data, rather than just reading or setting a field.

instructor.work(5); instructor.eat();See it: Encapsulation

Reference

What a class-type variable holds: the address of an object, so two variables can point to the same one.

Person instructor = new Person(name, age); // instructor holds the referenceSee it: Two Names, One Object

null

The value of a reference that points to no object; calling a method on it throws NullPointerException.

String[] names = new String[3]; // null null nullSee it: Arrays and Indexes

Overloading

Overloading

Several methods with the same name in one class, each with a different parameter list.

eat() eat(int amount)See it: Method Overloading

Signature

A method's name plus the types of its parameters in order; the compiler uses it to pick an overload.

greet(String, int) // greet_String_intSee it: Method Overloading

Parameter list

The types, count and order of the values a method or constructor takes.

(String otherName, int times)See it: Method Overloading

Constructor overloading

Giving a class more than one constructor so an object can be created in more than one way.

new Person() new Person("Ray") new Person("Raymond", 35)See it: Constructor Overloading

No-argument constructor

A constructor that takes nothing and sets default values; Java stops giving you one once you write any constructor.

public Person() { } // person: every field keeps its defaultSee it: Constructor Overloading

Loops

Loop

A block of code that repeats while a condition stays true.

See it: Three Loops, One Job

Iteration

One pass through the body of a loop.

See it: Three Loops, One Job

while loop

Checks the condition before every pass, so the body may run zero times; good when you do not know the count.

while (savings < 100) { ... }See it: Three Loops, One Job

do / while loop

Checks the condition after each pass, so the body always runs at least once.

do { ... } while (lap <= 3);See it: Three Loops, One Job

for loop

Puts start, condition and update on one line; good when you know how many times to repeat.

for (int item = 1; item <= 4; item++)See it: Three Loops, One Job

Counter

A variable the loop changes on every pass so that the condition eventually turns false.

week++;See it: Three Loops, One Job

Running total

A variable declared before the loop, starting at 0, that the loop adds to on each pass.

int total = 0; total += week;See it: Three Loops, One Job

Infinite loop

A loop whose condition never becomes false, usually because the counter is never updated.

while (week <= 4) { } // no week++See it: Three Loops, One Job

break

Leaves the loop at once and continues with the code after it.

if (i % 3 == 0) { break; }See it: break vs continue

continue

Skips the rest of the current pass and goes on to the next one.

if (i % 3 == 0) { continue; }See it: break vs continue

Arrays

Array

A fixed-size list of values of one type, stored side by side.

int[] newArrayOfNumbers = new int[5];See it: Arrays and Indexes

Element

One value stored in an array.

listOfNumbers[1] // the second element, 123See it: Arrays and Indexes

Index (subscript)

The position of an element in square brackets, from 0 up to length - 1.

listOfNumbers[listOfNumbers.length - 1]See it: Arrays and Indexes

length

How many slots an array has; no parentheses, unlike length() on a String.

cities.lengthSee it: Arrays and Indexes

Default value

What every slot of a new array holds before you fill it: 0 for numbers, false for boolean, null for Strings and objects.

new int[5] // 0 0 0 0 0See it: Arrays and Indexes

Array literal

Values in curly braces that create and fill an array in one step; the size comes from the count.

String[] cities = {"Beirut", "Boston", "Chicago"};See it: Arrays and Indexes

for-each loop

Visits every element in order and hands you the value, with no index.

for (String city : cities) { ... }See it: for-each vs for

Array parameter

A method can take or return an array with no size in brackets; what travels is the reference, so the method reads the caller's array, not a copy.

public static void displayNumbers(int[] listOfNumbers)See it: Arrays and Indexes

Array of objects

An array whose slots hold references to objects; each slot is null until you put an object in it.

Person[] team = new Person[4];See it: Arrays and Indexes

Arrays.toString()

Turns an array into readable text like [22, 24, 19]; printing the array itself shows only its reference.

System.out.println(Arrays.toString(cities));See it: Sorting and Copying Arrays

Arrays.sort()

Sorts an array in place in its natural order: smallest number first, Strings alphabetically.

Arrays.sort(cities);See it: Sorting and Copying Arrays

Arrays.copyOf() / System.arraycopy()

Copy elements into a separate array; assigning one array variable to another copies only the reference.

System.arraycopy(colors, 2, copy, 2, 3);See it: Sorting and Copying Arrays

Arrays.fill() / Arrays.equals()

fill() puts one value in every slot; equals() is true when two arrays hold the same values in the same order.

Arrays.fill(nextWeek, 20);See it: Sorting and Copying Arrays

Arrays.binarySearch()

Finds a value in a sorted array and returns its index, or a negative number when it is not there.

Arrays.binarySearch(cities, "Chicago")See it: Sorting and Copying Arrays
