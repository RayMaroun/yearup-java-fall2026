The one idea

Indexes start at 0 and end at length - 1, so a loop runs while i < array.length. A new array is never empty: new int[n] starts at zeros, String at null, boolean at false. An index equal to the length has no slot, and Java stops with ArrayIndexOutOfBoundsException.
