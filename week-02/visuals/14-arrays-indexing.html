Arrays and Indexes

Boxes in a row, counted from 0. Click one. Then ask for one too many.

int[]listOfNumbers
value
 
.length = 7
Seven boxes, one value each. The number under a box is its index, and it starts at 0.

The one idea

An array is a fixed row of boxes, numbered from 0. listOfNumbers[i] reads or writes box i. With 7 boxes the last index is 6, which is length - 1. Index 7, or -1, is not a box, so Java stops with ArrayIndexOutOfBoundsException.
