The one idea

An array has a fixed number of slots, set when it is created. Indexes run from 0 to length - 1, which is why the loop uses i < array.length. A new array is never empty: int slots start at 0, String slots at null. Ask for any index outside that range and Java stops with ArrayIndexOutOfBoundsException.
