The one idea

An array variable holds a reference, an arrow to the slots. Passing it to a method copies the arrow, so the method works on the caller's array and the changes stay after it returns. An int parameter is a copy of the value: changing it never reaches the caller. Returning an array hands the arrow back, and the array lives on after the method ends.
