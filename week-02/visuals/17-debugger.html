The Debugger

Put a red dot on a line. Run. Step. Watch the values.

Seven lines, no breakpoint yet. Click the gutter next to a line number to put a red dot there.

The one idea

A breakpoint is where Debug pauses, and the blue line has not run yet. Step over runs one line, Resume runs to the next red dot or to the end, and Variables shows the values right now. Reach for it when the code runs but the answer is wrong.
