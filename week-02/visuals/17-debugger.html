The Debugger

The debugger pauses your program on a line you choose, so you can run it one line at a time and watch the values change.

The one idea

A breakpoint, the red dot in the gutter, is where Debug pauses. While paused, the highlighted line has not run yet. Step Over runs one line, Resume runs until the next breakpoint, the Variables pane shows the values right now and the Frames pane shows which method you are in. Reach for it when the code runs but the answer is wrong.
