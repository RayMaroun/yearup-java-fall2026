The one idea

A method's signature is its name plus its parameter types. Methods in one class may share a name as long as the signatures differ. At each call the compiler compares the arguments with every parameter list of that name, by type, count and order, and if none fits, the code does not compile. The return type is not part of the signature, so it cannot tell two methods apart.
