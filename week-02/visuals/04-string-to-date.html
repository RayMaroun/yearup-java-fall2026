The one idea

A typed date is only text. LocalDate.parse(text) reads yyyy-MM-dd and nothing else. Any other shape needs a DateTimeFormatter whose pattern matches the text piece by piece, or Java throws a DateTimeParseException. Once parsed, it is a real date you can ask questions, like which day of the week it was.
