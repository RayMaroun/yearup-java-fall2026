Cell Phone Service, One-Line Phone

A second constructor that takes all five values at once, and a third phone built with it in one line.

What you are building

Your exercise 2 program in a new project, with a second constructor in CellPhone that takes five parameters, one per field. main builds a third phone with it, displays it and dials it. Optional: a second dial that takes a whole CellPhone instead of a number.

The no-argument constructor stays; phones 1 and 2 still use it. The lesson is overloading: same name, different parameter lists, and Java picks the one that matches what you pass.

Where people get stuck

  • "constructor CellPhone cannot be applied". The values do not match the parameter list: count, order or type.
  • Phones 1 and 2 broke. The no-argument constructor was replaced instead of kept. A class can have both.
  • The third phone shows 0 and blanks. The constructor received the values but never stored them: a parameter with the field's name needs this.
  • "String cannot be converted to int". The serial number went in quotes. Numbers go in without them.

The one idea

Overloading is the same name with different parameter lists. Java picks the constructor or method whose parameters match what you pass.
