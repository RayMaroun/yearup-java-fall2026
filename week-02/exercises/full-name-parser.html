Full Name Parser

A program that reads a whole name on one line and splits it into first, middle and last name.

What you are building

A program that asks one question and reads a name in one of two shapes: first last, or first middle last. It prints three lines: first, middle and last name, with (none) when there is no middle name.

It is Full Name Generator in reverse. It does not handle suffixes or names of four words.

Do these in order

0 of 7 done

What a finished run looks like

run
Please enter your name: Dana L. Wyatt First name: Dana Middle name: L. Last name: Wyatt

Yours will differ. With a two-word name the middle line reads Middle name: (none).

Where people get stuck

  • Index out of bounds. Asking a two-word name for a third piece crashes. Check the count first.
  • Empty first name. Splitting before trimming turns the leading spaces into an empty piece.
  • Off by one. The first piece is at index 0, not 1.
  • Two spaces between words also make an empty piece. Type the name with single spaces.

The one idea

Trim, split, then count the pieces. The count tells you which shape of name you got, and so where each part sits.
