Full Name Generator

A program that asks for the parts of a name and joins them into one full name, leaving out the parts left blank.

What you are building

A program that asks for four parts: first, middle, last name and suffix. First and last are always there; middle and suffix may be left empty. It prints one line: the full name, with a comma before a suffix.

It does not fix spelling or capitals. New this week: trimming spaces and deciding whether a part is empty.

What a finished run looks like

run

Your names will differ. Try all four shapes from the workbook: with and without a middle name and a suffix.

Where people get stuck

  • Double space. A blank middle name must not leave Glen Williams. Add the space only with the part.
  • Spaces are not empty. A middle name of one space counts as text until it is trimmed. Trim first, then check.
  • Blank Enter ignored. next() waits for a word. Use nextLine() for every part.
  • Check never true. Comparing text with == is unreliable. Use a String method instead.

The one idea

Trim first, then decide. Each optional part goes in only when it has text, together with its own space or comma.
