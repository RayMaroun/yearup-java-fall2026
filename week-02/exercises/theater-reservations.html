Theater Reservations

A program that takes a name, a date and a ticket count, then prints one confirmation line.

What you are building

A program that asks three questions: full name, the show date as MM/dd/yyyy, and how many tickets. It prints one line: the count, the date, and the name turned around as Last, First.

It does not check seats or prices. The details that matter: ticket or tickets, and a date read in one format and printed in another.

Do these in order

0 of 9 done

What a finished run looks like

run
Please enter your name: Geri Johnson What date will you be coming (MM/dd/yyyy): 05/13/2023 How many tickets would you like? 3 3 tickets reserved for 2023-05-13 under Johnson, Geri

Yours will differ. With 1 ticket the line reads 1 ticket reserved for ...

Where people get stuck

  • DateTimeParseException. Pattern letters are case sensitive: MM is month, mm is minutes.
  • 1 tickets. The s must depend on the count.
  • Date looks different. The output shows 2023-05-13: that is how a LocalDate prints by itself.
  • Name backward twice. The first piece is the first name; print the last name first.

The one idea

Read text, convert it, then build the sentence. The date becomes a LocalDate, the count picks ticket or tickets, the name is cut at the space and turned around.
