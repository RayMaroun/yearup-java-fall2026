Address Builder

A program that asks for a name and two addresses, builds one block of text with a StringBuilder, then prints it.

What you are building

A program that asks nine questions: full name, then street, city, state and zip for billing, and again for shipping. It prints the customer block: name, billing address, shipping address, each on its own lines.

It does not validate zips or states. The point is the tool: one StringBuilder that grows with append(), not a String rebuilt again and again.

Your addresses will differ. The shape of the block is what matters.

Where people get stuck

  • All on one line. The builder adds no line breaks by itself. Append them.
  • Middleton,TX75111. The comma and spaces are yours to append too.
  • Lost zero. Read with nextInt(), a zip like 02134 drops its zero. Read it as text.
  • Using +=. It works, but it skips the point of the exercise: use append().

The one idea

A String never changes; a StringBuilder does. Append each answer as it arrives and print the finished text once.
